# 입문3: 무력화·보호·생존 탈출

M06의 전투 기반이다. [첫 챕터 기획](SCENARIO_FIRST_CHAPTER_PROPOSAL.md)의 A3 묶음과 [확정 C1~C9](SCENARIO_QUEST_DIALOGUE_DESIGN.md)를 따른다. M06 개인 의뢰·다온 대화·구출의 서사 사건 연결은 후속이며, 이 실습 정산을 챕터 완료로 취급하지 않는다.

## 플레이

`Scripts/Start-TrainingDevelopment.ps1 -DungeonProfile Intro3`은 명시적인 Development/Testing 프로필에서 Training/Intro1/Intro2/Intro3 Normal을 제공한다. 캐릭터 자신의 입문2 완료 기록이 있어야 입문3에 입장한다. 기존 프로필·훈련·성장·스킬 습득/수동 편성·입장 인증 조건은 유지한다. `-ChapterOne`으로 기존 M01~M05도 함께 진행할 수 있다.

전용 맵 `/Game/Maps/Progression/L_ProgressionIntro3`에서 세 단계를 같은 시도에 성공한다.

1. 정면 표적에 실제 차지·도약·회전 종료 타격을 적중해 무력화 기여100을 누적한다. 부위 파괴와 합산하지 않으며, 보스 그로기 구현과도 구분한다. 차지만으로도 참여할 수 있다.
2. 보호 대상 체력100을 지키며 45초를 버틴다. 시작과 22.5초에 각각 적2기가 출현한다. 적은 3초마다 기존 GAS의 서버 승인 피해로 보호 대상을 공격한다. 두 웨이브의 적을 모두 제거하고 45초가 끝나야 방어가 완료된다. 적 체력30·공격 기본값12는 첫 플레이 검증용 수치다.
3. 방어 후 25초 안에 북동쪽 원형 안전지점으로 살아서 이동한다. 방어 전에 안전지점을 선점했다면 밖으로 나왔다가 다시 진입해야 한다. 현재 참가자 전원이 도착하고 기존 파티 정산 검사가 확정할 때까지 머무른다. 광산 외부로의 최종 반출은 후속 M07이다.

안내 카드에 시도 번호·무력화 수치·보호 대상 체력·남은 시간·개인 탈출 진도를 표시한다. 고정 보호 대상과 고정 공격자를 사용하며 이동 호위 AI를 추가하지 않는다. 캐릭터와 적 외형은 기존 실습용 에셋을 재사용한다. 실제 사망한 실습 적은 즉시 퇴장시켜 다음 웨이브 접근로를 막지 않게 한다.

## 권한과 저장

- 현재 인증·입장 확인·Normal 서버 할당·불변 스킬 복원·살아 있는 전투 수명이 모두 일치해야 시작한다. 진행 수치를 제출하는 RPC는 없다.
- 기존 기여 수신기가 현재 표적의 현재 세대에 승인한 스킬 적중만 사용한다. 같은 능력 활성화의 중복 적중 방지는 기존 수신기를 재사용한다. 파티의 표적 누적량을 공유하되 개별 참가 자격·수명·탈출을 검사한다.
- 보호 대상 사망, 시간 초과, 참가 명부/Pawn/Controller/연결·복원 세대 변경은 묶음 전체 실패다. 3초 후 표적·보호 대상·적·누적량·탈출 사실을 새 시도로 초기화한다. 재접속은 과거 기여나 방어 진도를 복구하지 않는다.
- 전원 완료 후 시작한 최신 멤버십 조회를 요구하는 기존 `ARPGTrainingGameMode` 경로로 한 번 정산한다. 조회 사이에 안전지점을 벗어나면 완료 자격을 잃는다. 개인 목표 완료 화면과 백엔드 정산 확정은 구분한다.
- 성공 영수증은 기존 Intro3 정책을 따른다. XP100·광석2, 순차 최초 진행 후 누적 XP400·SP12·성장 milestone15다. 의뢰 추가 보상·성장 보정·스킬 자동 편성은 없다. 이미 확정된 정산은 이후 단절로 취소하지 않는다.

## 작성과 검증

`Scripts/Editor/CreateProgressionIntro3Content.py`는 호환 모듈에서 읽기 검사한다. `RPG_INTRO3_REPORT`를 절대 JSON 경로로 지정하고 `-RPGCreateProgressionIntro3Content`를 추가한 경우에만 없는 소유 에셋5개를 생성한다. 기존 보상·선택 정의·다른 맵은 보존한다. 소유 표식 불일치·미저장 변경은 덮어쓰지 않는다.

`ProjectRPG.Progression.Intro3` native automation은 무자격 참가·RPC 부재·선행 실습 선택·묶음 완료 경계를 검사한다. 백엔드 ContentProfileTests의 `--intro3-only`는 정확한 네 맵·선행 조건·인증/서버 범위·실제 HTTP 정산·성장 중복 방지를 검사한다.

`Scripts/Tests/Run-ChapterOnePlaytest.ps1 -RuntimeProjectRoot <호환 프로젝트> -BackendRoot <고정 Backend> -RescuePractice`는 실제 훈련부터 순차 성장한 캐릭터로 입문3에 진입한다. 일반 입력·이동으로 기여 후 프로세스 재시작, 실제 공격에 의한 보호 실패, 새 시도 전체 초기화, 두 웨이브/45초 방어, 선점 거절·재진입·생존 탈출·실제 정산을 확인한다. 목표·체력·성장·클리어를 검증 드라이버에서 주입하지 않는다. 자기 실행 프로세스와 임시 UserDir·백엔드 출력을 종료 후 정리한다.

최소 근거는 로컬 `Saved/BuildChecks/Intro3Rescue-20261117`에 보존한다. 개발 인증·Memory·Iris·합성 입력의 범위이며 Steam·PostgreSQL·다인 물리 입력·Shipping/cook과 구분한다. 실행 중인 원본 에디터/DLL은 보존한다.
