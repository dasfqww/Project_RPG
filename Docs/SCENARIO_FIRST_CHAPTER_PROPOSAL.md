# 첫 챕터 콘텐츠 기획 — 폐광의 실종자

작성일: 2026-11-03

버전: 0.2 / 개정일: 2026-11-15 / 상태: **사용자의 기획 판단 위임에 따라 선택한 첫 챕터 작업 기준안. 플레이 가능한 콘텐츠·출시 수치·실행 검증 완료를 뜻하지 않는다.**

상위 기준은 [시나리오·퀘스트·대화 통합 기획안](SCENARIO_QUEST_DIALOGUE_DESIGN.md)이다. 2026-11-15 사용자의 “니 소신대로 작업해봐”에 따라 외부인 주인공·폐광 구조 사건을 선택하고, 본 문서를 콘텐츠 기획의 작업 기준으로 구체화했다. 아래 창작 선택은 기획 담당의 판단이며 사용자가 인물·문장마다 직접 지정한 사실로 기록하지 않는다. 기존 확정 C1~C9와 성장 계약은 유지한다. 이번 완료 단위는 서사·퀘스트·대사·장면의 문서 저작이며 게임 코드·카탈로그·맵·에셋 제작은 포함하지 않는다.

## 1. 제작 목표와 범위

- 플레이어가 ‘왜 준비하고, 무엇을 조사하며, 누구를 도와야 하는지’를 이해한다.
- 기존 첫 성장 구간의 Training → Intro1 → Intro2 → Intro3 → FirstBoss Normal 흐름을 이야기와 연결한다.
- 기존 Training·Intro1의 승인된 실습 목표를 다른 목표로 덮지 않는다. NPC·조사·추가 사건과 아직 연결되지 않은 A2/A3 콘텐츠는 신규 저작으로 구분한다.
- 메인 8개, 선택 서브 2개, 주요 NPC 4명을 챕터 작업 분량으로 삼는다. 첫 플레이 검토 구간은 M03 외곽 조사로 좁힌다.
- 처음 보는 사람과 완료한 친구가 함께 진행할 수 있고, 반복 입장과 부캐 스킵에서는 긴 대사·귀환 보고를 반복 요구하지 않는다.

가칭과 `CH01.*` ID는 기획 식별자다. 실제 카탈로그·맵 패키지·퀘스트 API에 이미 등록된 값이 아니다. 실존하는 다른 작품의 지역·인물·대사를 재현하는 기획은 아니다. 현재 기반의 지원 범위는 [저작 계약](NARRATIVE_CONTENT_AUTHORING.md)과 [런타임 계약](NARRATIVE_RUNTIME.md)을 따른다. 이 문서의 자동 완료·과거 실습 인정·공동 조사·연출 요구가 전부 현재 JSON으로 실행된다고 해석하지 않는다.

## 2. 이야기와 인물

**중심 주제: 마을을 지킨 사람들을, 이제 마을이 버리지 않는다.** 분위기는 생활감 있는 모험과 긴장, 구조 뒤의 작은 안도다. 피해 규모나 잔혹 묘사로 감정을 강요하지 않는다.

플레이어는 일거리와 현장 경험을 찾으러 온 외부인이다. 출신·성별·혈통·특정 인물과의 과거 관계를 고정하지 않는다. 미라는 아직 위험의 실체를 몰라 ‘연락이 끊긴 수레의 위치와 생존 여부 확인’을 맡긴다. 별도 착수금·추가 의뢰 재화를 약속하지 않으며 실제 보상은 4·9절의 기존 정산만이다. 로엔은 현장에 보낼 사람의 기본 동작을 확인한다. 생존 신호를 듣기 전까지 ‘몇 분 안에 구조하지 않으면 죽는다’는 시한을 만들지 않는다.

광석 수입에 의존하던 마을은 폐쇄 갱도의 일부를 최근 다시 파기 시작했다. 운송이 끊기자 약탈 소문이 돈다. 외곽에 도착한 플레이어는 화물이 남은 수레, 안쪽의 버팀대, 생존 신호를 차례로 확인한다. ‘누군가 안에서 일부러 막았고 아직 사람이 있다’까지 추론하지만 목적과 괴물의 정체는 모른다. 단순 조사였던 일이 살아 있는 사람에게 도달해야 할 이유로 바뀐다.

점검 통로 안에서 만난 다온은 광부들이 깨어난 괴물을 막으려고 주갱도를 봉쇄했다고 증언한다. 다온은 깊은 작업장에 남은 부상자들을 돌보며 대피실로 옮길 방법을 찾고 있었다. 괴물이 있는 넓은 주갱도를 열어야 들것을 옮길 수 있다. 플레이어는 내부 안전지점까지 구조 대상을 확보한 뒤 괴물을 제압하고 봉쇄를 안전하게 해체해 마을로 돌아온다.

결말에서 미라는 채굴·민간 운송을 중단하고 구조와 안전 확보를 우선한다. 구조된 사람들은 이번 사건에서 실제로 돌아온다. 그 뒤 인접 갱도에서도 비슷한 손상 보고가 왔다는 정보만 남긴다. 원인이 같다고 확정하거나 첫 구조 결말을 취소하지 않는다. 공동 전술 분기는 초판에 넣지 않고 하나의 점검 통로로 진행한다. 개인 후일담의 태도 차이만 남긴다.

인물 관계 수치 시스템은 이번 제안에 추가하지 않는다. 개인 태도 선택은 필요한 후일담 대사에만 반영하며, 서로 다른 보상이나 필수 해금으로 연결하지 않는다.

미라·로엔·유나는 거점에 남는다. 던전 안에서 그들의 실시간 음성이나 순간 합류를 사용하지 않는다. 내부 안내는 다온·환경·짧은 목표 문구가 맡는다. 캐릭터의 독백·음성도 필수로 추가하지 않는다. 혼합 파티의 완료자에게 처음 만난 외부인이라는 개인 과거를 다시 기록하지 않는다.

표의 공간 수만큼 새 맵을 만든다는 뜻은 아니다. 동일 공간의 구역·사건 경로로 묶을 수 있다. 공유 공간의 조사·NPC 상태는 클라이언트만으로 완료시키지 않는다. 서버 권위 경로와 영속 퀘스트 연결은 이 챕터의 요구이며, 재사용·추가 구현 범위는 최신 계약과 호출 코드 대조로 확정한다.

외곽 조사 장소는 조사 의뢰 수락 후 접근할 수 있어야 한다. Intro1 실습 맵 안에 배치하는 경우에는 **Intro1 이야기 입장을 조사 완료로 잠그지 않고**, 조사 완료가 맵 내부의 실습 구간을 연다. 별도 공간으로 작성할 경우에도 조사할 수 없는 공간의 조사 완료를 입장 조건으로 요구하지 않는다.

### 3.1 공간 인과와 인물 위치

주갱도의 순서는 **외곽 → B 봉쇄 → C 운반실 → D 내부 대피실 → E 깊은 작업장**이다. 별도의 **외곽 → 좁은 점검 통로·사다리 → E 인근 점검실**이 플레이어의 진입로다. B~E는 기획 구역 표기이며 별도 맵 네 개를 요구하지 않는다.

| 시점 | 위치·행동 | 다음 구간이 필요한 이유 |
|---|---|---|
| 사고 직후 | 광부들이 B에 안쪽 버팀대를 설치하고 측면 작업 통로로 E까지 후퇴. 대형 괴물은 C에 남음 | 마을로 나가는 길을 막은 대가로 자신들의 반출로도 끊김 |
| M03~M04 | 외곽에서 봉쇄를 조사한 뒤 점검 통로로 접근 | B를 유지해 C의 괴물이 밖으로 나가지 않게 하며 내부 생존자를 확인 |
| M05 | E 인근 점검실의 다온 발견. 부상자는 E에 흩어져 있음 | 점검 통로의 폭·사다리는 들것에 부적합. 보스도 이 통로를 통과할 수 없음 |
| M06 | E에서 고정 방어 후 붕괴 위험 구간을 벗어나 D 확보 | D의 차단문 뒤에 구조 대상을 보호. 이것은 내부 대피이며 광산 밖 구조 완료가 아님 |
| M07 | 플레이어가 D에서 C로 나가 보스 제압 → 안전 확인 → B 버팀대 해체 → D의 환자를 B 밖으로 반출 | 봉쇄부터 풀어 괴물을 마을로 보내는 역전 방지. 보스 사망만으로 문이 저절로 사라지지 않음 |
| M08 | 외곽에서 기존 복귀 경로로 거점에 돌아와 미라에게 보고 | 미라·로엔에게 현장 결과 전달. 순간이동하는 구조 조력자 없음 |

D 차단문은 M06의 소형 적을 잠시 막는 기존 시설이라는 설정이다. 영구 무적 공간·보스를 가둘 새 기믹으로 확장하지 않는다. 환자 이동은 안전한 구간 전환과 C02 장면으로 표현하며, 초판에 들것 운반 조작·이동 호위 AI를 추가하지 않는다. 다온은 걸으며 도구를 쓸 수 있으나 부상자들을 혼자 반출할 수 없는 상태다.

| CH01.M08 돌아온 사람들 | M07 이야기/개인 보고 자격 | 미라에게 보고 1회, 후일담 선택 | 보고 승인 재시도 동일 처리. 보상 미확정 중 완료 대사 금지 | 챕터 직접 완료·다음 지역 이야기 해금·계정 스킵 자격. 추가 성장 보상 0 |

각 메인은 제시와 개인 수락을 구분한다. M01~M07은 수락 후 정의된 목표가 모두 승인되면 공통 완료 절차로 자동 완료하며, M08은 미라에게 개인 보고한다. 다음 의뢰는 앞선 완료 응답이 확정된 뒤 제시하고 자동 수락하지 않는다. 현장·목표 화면에서도 수락할 수 있게 하여 의뢰마다 거점 귀환을 요구하지 않는다.

M01 수락 승인 뒤 D01의 상황 증언을 첫 근거로 남기고, D02에서 로엔의 준비 설명을 확인한 선택을 두 번째 근거로 남긴다. 두 근거 승인 → M01 완료 확정 → M02 제시·개인 수락 순서다. 단순 소개 열람·창 닫기·훈련 버튼 노출만으로 이 순서를 통과하지 않는다.

M02/M04/M05/M06/M07의 전투 실습 목표는 유효한 기존 완료 영수증을 참조할 수 있다. 의뢰 수락 전에 이미 해당 실습을 완료했다면 본인·콘텐츠·정의 버전·실적을 확인해 인정할 수 있도록 **이 다섯 의뢰의 전투 실습 목표에만 기존 실적 인정 정책을 명시**한다. 일반 처치·단서 전체의 무조건 소급 인정으로 확대하지 않는다.

과거 영수증은 해당 버전·경로가 증명하는 전투 실습만 충족한다. 다온 발견 등 개인 서사 목표는 별도 승인 근거가 필요하며, 같은 시도 구출·방어·탈출을 증명해야 하는 경우에는 전체 묶음의 동일 시도 근거가 있어야 한다. 옛 실습 완료 기록으로 새 서사 사건을 수행했다고 기록하지 않는다. 이미 인정된 기존 실습은 새 서사 추가를 이유로 다시 요구하지 않고, 부족한 서사만 진행할 조사/회상 진입점을 작성한다.

| 구성 | 실제 실습·정산 조건 | 개인 서사 조건·스킵 처리 |
|---|---|---|
| M05 / Intro2 | 승인된 공격 기회 대응 2회 등 해당 버전의 실습 성공 | 다온 발견은 별도 개인 사건. 직접 서사 진행자는 발견 근거가 필요하고, 스킵자는 이 의뢰를 재수행하지 않음 |
| M06 / Intro3 | 기여·방어·생존 탈출의 같은 시도 성공 묶음 | 인물 소개·구출 이유·장면은 서사 경로. 스킵/반복 경로에서도 보호 대상과 실제 방어·탈출 규칙은 유지 |
| M07 / FirstBoss Normal | 기존 보스 성공 정산과 Hard 해금 | 직접 서사 경로의 주갱도 개방·환자 반출 결과는 별도. 스킵/반복의 전투 정산에 새 서사 조건을 붙이지 않음 |

M05/M06의 새 콘텐츠 목표가 실제로 구현돼 있다는 뜻은 아니다. 기존 목표·정산 경계를 유지하며 별도 에셋·사건·승인 근거를 작성해야 한다. 성공 정산은 해당 버전의 모든 필수 **실습 성공 조건**이 충족됐을 때만 보낸다. 개인 서사 의뢰의 보고 가능 여부와 전투 정산 성공을 별도로 판단하며, 다온 발견·대화 종료가 전투 클리어를 대신하거나 스킵자의 정산을 막지 않는다.

v0.2의 M07 반출은 새 서사 사건 요구다. 권위 있는 이야기 사건이 C의 안전·B 개방·D 반출을 순서대로 확정하고, 개인 목표는 본인의 자격과 해당 구조 시도를 확인한다. C02 재생·보기 완료 버튼은 그 근거가 아니다. 정산 후 단절되면 이미 승인된 전투 결과를 보존하고 미확정 반출만 복구하는 현장/거점 재개 경로가 필요하다. 최초 제작에서 이 복구 경로를 구현하지 않은 채 ‘구조 완료’ 대사로 덮지 않는다. 완료자 동행·회상 진입 역시 현재 필요한 구조 사건과 연결하며 과거 보스 영수증 하나로 반출을 소급하지 않는다.

승인 스킵자는 M07 개인 의뢰 대신 별도 실제 보스 진입 경로를 사용한다. 이 경로의 성공은 기존 전투 실적·보상만 갱신하며, 스킵 종료된 M07/M08을 재개하거나 챕터 직접 완료로 바꾸지 않는다.

Hard는 기존 Normal 실제 첫 클리어 조건을 유지한다. M08 귀환 보고를 새 Hard 입장 조건으로 추가하지 않는다. 다른 다음 지역은 아직 정의하지 않았으므로 M08의 해금은 해당 지역이 제작·등록됐을 때 연결한다.

Training 이전에는 회전·고유 능력을, Intro1 완료 이전에는 도약을 필수 목표로 요구하지 않는다. 기여 목표에는 당시 습득 가능한 차지/도약 등 참여 방법을 제공한다. 특정 트라이포드 선택·고강화를 의뢰 완료 조건으로 강제하지 않는다.

호위를 실제로 이동하는 NPC로 확장할 때에는 이동 실패·전투 이탈·복구 지점 등 별도 구현이 필요하다. 첫 제안은 통합 기획안의 호위 지원 방향을 유지하되 A3의 구체 제작은 고정 위치 방어와 안전한 탈출 구간부터 검토한다.

S01의 장갑은 유나의 동생 태오가 남긴 것이다. 이름표와 매듭을 통해 주인만 확인하며 물건으로 사망을 판정하지 않는다. M08 직접 완료 또는 챕터 스킵으로 사건이 정리된 세계의 후일담에서는 태오가 구조 대상 중 한 명으로 돌아왔음을 알 수 있다. 태오는 이름 있는 배경 생존자이며 별도 주요 NPC·대화창·음성 배역을 추가하지 않는다. S01은 M08 전에도 보고 완료할 수 있다. 이후 대사 조건만 달라지고 최초 보상을 다시 처리하지 않는다.

S02의 운송 기록에는 광석 수량 옆에 ‘늦는 사람 몫의 식사 남겨둘 것’이라는 부탁과 확인 표시가 있다. 업무 기록 사이에서 서로를 챙긴 사람들을 발견하게 한다. 완료 뒤 미라는 공용 식사 자리를 정리하겠다고 말한다. 배경 식탁 표현은 선택 저작이며 음식 아이템·회복 버프·새 일일 의뢰를 만들지 않는다. 두 서브의 후속 대사는 14절을 따른다.

| CH01.D12 | 유나 / S01 보고 가능 | “이 매듭, 태오가 묶은 게 맞아요. 제 장갑도 늘 이렇게 묶어줬죠. 누구의 것인지 확인해 줘서 고마워요.” | 서브 보고·사건 기록. 물건으로 생사 단정 없음. 메인 해금 변화 없음 |

첫 수락의 “나중에 오겠다”는 창 닫기이며 포기·실패가 아니다. 이미 확인한 소개는 반복 방문에서 역할 목록으로 바로 접근할 수 있다. 여러 의뢰 보고·상점 등의 기능이 있다면 현재 자동 대사가 가리지 않는다.

위 조건은 개인 의뢰 진행용 진입점이다. 스킵자가 친구의 사건을 함께 감상하거나 다시보기를 선택할 때에는 별도 감상 진입점을 사용하며 개인 의뢰를 수락·재개하지 않는다. M05/M07의 새 의뢰 수락은 앞선 의뢰 완료 후 현장 목표 화면에서도 제공한다.

| 역할 ID·NPC | 표시·선택 | 승인 이후 |
|---|---|---|
| CH01.R.S01_ACCEPT / 유나 | ‘남겨진 장갑 조사’. S01 미수락·접근 조건 충족 시 개인 수락 | 장갑·이름표 단서2 목표 표시. 완료 보고는 D12 사용 |
| CH01.R.S02_ACCEPT / 미라 | ‘운송 기록 부탁’. S02 미수락·접근 조건 충족 시 개인 수락 | 기록 확인·퀘스트 전용 기록 전달 목표 표시 |

이 역할 항목은 메인 완료·스킵 후에도 남는다. S01/S02 수락 전 단서 열람을 무조건 소급하지 않으며, 수락 후 승인된 조사만 목표로 인정한다. 이 보조 역할 대사는 핵심 문구12개(NPC 문구11·D04 목표 UI 1) 외의 서브 후속 저작 분량이다.

M08 보고 후 태도 선택 후보는 “남은 사람들도 살펴야 합니다”와 “원인을 더 조사해야 합니다”다. 각각 후일담의 한 문장을 달리하되 첫 챕터 결말·해금·보상은 같다. 선택한 경우에만 개인 기록을 남기며, 스킵자는 두 태도 중 하나를 골랐다고 기록하지 않는다.

위 12개는 핵심 문구의 기획 ID다. D04는 NPC 대화 노드가 아닌 목표 UI 텍스트로 인계하며, 나머지 문구도 실행 정의와 번역 키의 매핑이 필요하다. 최종 음성·표정·카메라가 실제 저작돼 있다는 뜻은 아니다. 음성이 없어도 문장과 목표 안내로 진행 가능해야 한다.

## 8. 공동 선택과 연출

v0.2의 첫 챕터는 점검 통로 한 경로로 진행한다. v0.1의 ‘정문 돌파 / 배수로 진입’과 투표 대기는 초판 제작 범위에서 유보한다. 봉쇄를 먼저 여는 선택으로 마을을 위험에 빠뜨리거나, 생존자를 버리는 선택은 넣지 않는다. 개인 수락·정보 질문·M08 후일담 선택은 유지한다.

상위 문서 22.2절의 공동 투표는 향후 분기 콘텐츠를 위한 일반 설계안으로 남긴다. 이 챕터 제작을 위해 투표 시스템을 먼저 완성해야 하는 의존성을 두지 않는다.

| 장면 | 구성 | 시간 가설 | 반복 경로 |
|---|---|---:|---|
| CH01.C01 돌아갈 길 | D의 들것 → C의 보스와 B 봉쇄 → 다온 경고 → 조작 복귀 | 14초 | 짧은 현장 경고로 대체 가능하도록 별도 저작 |
| CH01.C02 밖으로 | C의 안전 → B 버팀대 해체 → D 환자 반출 → 외곽 귀환 안내 | 12초 | 정산·복귀 안내로 연결. 이미 구한 사람을 재실종시키지 않음 |

두 장면 모두 준비 대상·기한·실패 경로를 작성하고 개인 스킵은 안전대기로 연결한다. 초행은 기본 감상이며 직접 스킵할 수 있다. 전원 명시적 스킵이 성립하지 않으면 작성된 길이까지 진행한다. 수동 선택 대화의 답을 이 기한으로 자동 선택하지 않는다.

전투 중 “위쪽을 조심하세요” 같은 짧은 말은 입력을 점유하지 않는다. 장면 길이 26초는 9절의 추가 이야기 시간에 포함한다. 투표 삭제분을 다른 필수 대기·대화로 채우지 않는다. 자세한 장면 지시는 15절을 따른다.

## 9. 시간·보상·성장 합계

수치는 [첫 성장 구간 수치안](PLAYER_PROGRESSION_FIRST_SLICE_V01.md)의 기존 전투 가설을 기준으로 한다. 실제 플레이 측정 결과가 아니며 훈련·입문·보스의 기존 수치를 이번 문서 작성으로 수정하지 않는다.

| 구간 | 기존 콘텐츠 시간 | 추가 서사 시간 | 실제 콘텐츠 정산 XP | 광석/증표 |

| M02 Training | 10분 | 0분 | 100 | 0/0 |

| M04 Intro1 | 8분 | 1분 | 100 | 2/0 |
| M05 Intro2 | 8분 | 1분 | 100 | 2/0 |

| 합계 | **46분** | **9분** | **500** | **10/2** |

메인 성공 경로는 55분, 선택 서브 두 개까지 하면 63분 가설이다. 기본 빌드 형성 지점인 Intro3 완료는 기존34분+추가6분=40분으로 계획한다. 기존 시간에는 재정비·입장·정산이 포함되어 있으므로 이 시간을 다시 더하지 않는다. 실패·모집·긴 로딩·읽기 속도 차이는 별도 측정한다.

이 표는 v0.1에서 투표 최대20초를 포함했던 분 단위 예산을 유지한 것이다. v0.2에서 투표는 삭제했지만 54분40초를 새 실측값처럼 제시하지 않는다. 조사 정보의 전달력과 추가 반출 사건·구간 전환의 시간을 실제 플레이로 확인한 뒤 예산을 갱신한다.

신규 Lv1 캐릭터가 위 다섯 콘텐츠를 처음 성공하면 기존 규칙에 따라 누적500XP/Lv6/총14SP다. 서사 의뢰가 같은 XP500을 다시 지급하지 않는다. 광석10·증표2는 소비 전 누적 지급량이다. 보스의 개인 장비 추첨은 기존20%·4종 균등 가설을 유지하므로 각 종류의 클리어당 확률은5%이며, 장비가 반드시 하나 나오는 경로가 아니다.

서브의 전투 성장 지급0은 이 제안의 선택이다. 인물 이야기와 기록을 보상으로 삼은 구성이 실제로 매력적인지 플레이 검토하고, 보상을 바꿀 때에는 성장 시간·선택성·스킵 정책을 함께 다시 계산한다.

## 10. 부캐·반복·혼합 진도

스토리를 건너뛴 부캐는 M01~M08의 이야기 선행을 충족하지만 기존 Training→Intro1→Intro2→Intro3의 **실제 실습 조건은 유지**한다. 부캐 화면은 ‘이야기 해금 완료’와 ‘현재 남은 실습 조건’을 별도로 표시한다. 실제 실습 성공마다 기존 정산 XP100·원래 재료를 지급하고, 스킵 자체는 XP·재화·장비를 지급하지 않는 안이다.

직접 완료 이후 일반 현장 방문은 잔류 위협 정리·구조와 안전 확보를 목적으로 안내한다. 이미 구조된 인물을 다시 실종자로 소개하지 않는다. 기존 보스를 같은 조건으로 다시 공략하는 메뉴는 ‘완료한 전투 다시하기’로 표시하며, 사건 시간선을 되돌리거나 같은 괴물이 부활했다고 기록하지 않는다. 전투 보상은 기존 반복 규칙을 따른다.

실습 진입은 긴 사건 대화·서사 조사·귀환 보고를 다시 요구하지 않는 직접 경로로 제공한다. 기존 Intro1의 실제 접근·회전 목표 등 실습 자체는 수행한다. 최초 실제 Normal 클리어 후 Hard가 열리는 조건도 그대로다. 스킵만으로 기존 성장 milestone을 세우거나, Training+Intro1만 마친 캐릭터가 Normal에 입장·정산할 수 있다고 가정하지 않는다.

이미 실습을 끝낸 부캐에게는 그 실적을 보존하며 중복 강제하지 않는다. 개인 전투력·SP·장비는 직접 얻은 상태 그대로다. 현재 첫 구간에는 새로운 장비 점수 하드게이트를 추가하지 않는다.

처음 보는 A, 완료한 B, 다른 단계 C가 함께 진행한다면 출발 화면에서 이야기/반복 경로와 진행 가능한 개인 목표를 표시한다. 핵심 조사·구출 사건이 필요한 사람이 있는 이야기 경로에서는 B의 완료 이력으로 문·NPC·사건을 생략하지 않는다. 반복 경로에 없는 사건의 달성을 클리어 결과만으로 대신 인정하지 않는다.

스킵자도 초행 친구의 이야기 경로에 동행해 장면을 감상할 수 있다. 감상이 이미 기록된 스킵을 직접 완료로 바꾸거나 최초 보상을 되살리지는 않는다. 자신에게 유효한 실제 실습·던전 보상은 기존 규칙대로 별도 처리한다.

## 13. 첫 제작 구간 — M03 조사에서 구조로

첫 플레이 검토 범위는 M03 수락부터 M04 제시까지다. 좁은 외곽 공간 하나에 세 단서를 배치한다. 이 구간의 성공으로 보스전·챕터 전체·협동 구조의 재미를 검증했다고 하지 않는다. 실제 플레이 전에는 아래 내용을 종이 동선·블록아웃 제작의 입력으로 쓴다.

| 기획 단서 ID | 직접 하는 행동·감각 정보 | 확인 뒤 짧은 문구 | 다음 목표·정보 경계 |

HUD 문구는 ‘수레가 멈춘 이유 확인 → 봉쇄가 만들어진 방향 확인 → 안쪽의 생존 신호 확인’으로 바뀐다. 세 단서의 정보 확인은 각각 유효한 목표가 승인된 뒤 갱신한다. 소리에는 같은 의미의 자막과 관찰 문구를 제공한다. 듣기 능력·음성 출력·색상 구별 하나만으로 필수 정보를 전달하지 않는다.

공간에서 단서를 먼저 보거나 전투 중 지나치는 것은 허용한다. 하지만 선행 목표가 준비되기 전의 열람은 완료 근거가 아니며, 활성화 뒤 다시 조사할 수 있다. 단서 오브젝트를 첫 조사자가 영구 소모하지 않는다. 이미 승인한 개인 단서는 재조회할 수 있고 중복 누적하지 않는다. 후발 파티원에게 발견 요약을 제공하더라도 정보 열람만으로 목표를 완료시키지 않는다. 현재 수락·선행·현장 참여가 유효한 사건 또는 재조사로 인정하며 다른 사람의 과거 진도를 복사하지 않는다.

필수 정보는 선택 서브를 하지 않아도 모두 얻는다. M03에서 해답을 미리 전부 말하는 내레이션, 미라의 원격 설명, 단서3개를 누르면 같은 대사가 세 번 나오는 구성을 피한다. 공동 조사 인정·재조사·요약 표시의 실제 구현 적합성은 저작 전에 최신 계약과 호출 경로로 확인한다.

검토자는 플레이 직후 다음 세 질문을 한다. 예상 답을 먼저 알려주지 않는다.

1. 무엇을 보고 처음 생각이 바뀌었는가? — 남은 화물이나 안쪽 버팀대 등 직접 본 근거를 말할 수 있어야 한다.
2. 지금 확실히 아는 것과 아직 모르는 것은 무엇인가? — 안쪽 봉쇄·생존 가능성과 봉쇄 목적·생존자 규모를 구분해야 한다.
3. 다음에는 어디로, 무엇을 확인하러 가는가? — 점검 통로로 생존자를 찾으러 간다는 이유가 전달돼야 한다.

답이 막히면 단서의 구도·동선·문구를 먼저 수정한다. 이 단계에서는 새 세계관 설명이나 조사 횟수를 늘려 해결하지 않는다. 읽는 시간·헤맨 지점·동료가 먼저 진행했을 때 놓친 정보도 함께 기록한다.

### 15.2 C02 밖으로 — 12초 가설

| 구간 | 화면·소리 | 사건과의 관계 |
|---|---|---|
| 0~3초 | C의 쓰러진 보스, 잦아든 진동 | 승인된 전투 결과 표현. 장면이 정산을 발생시키지 않음 |

실제 사건 상태가 장면보다 먼저 또는 별도 권위 전이로 확정돼야 한다. 보스 정산, B 개방, D 반출은 서로 다른 사실이다. 장면 시작·종료·스킵·재감상으로 이 사실이나 지급을 생성하지 않는다. 특히 C02 감상 완료만으로 M08 보고 자격을 부여하지 않는다. 사건 미확정이면 ‘구조 결과 확인 중’ 안내와 복구 경로를 제공하고, 결과는 확정됐으나 연출만 실패했다면 텍스트 요약과 기존 복귀를 제공한다.

두 장면 모두 음성 없이 자막·구도·목표 안내로 진행 가능해야 한다. 필수 내용은 대화 기록/사건 요약으로 재확인할 수 있게 저작하되, 정보 재열람으로 최초 선택·목표·보상을 다시 실행하지 않는다. 혼합 파티는 이야기 경로 선택 시 초행 사건을 함께 진행하고 완료자의 개인 진도는 유지한다. 반복 경로는 ‘완료한 전투 다시하기’이며 재실종·괴물 부활을 정사로 기록하지 않는다.
