# 첫 챕터 제작 제안 — 폐광의 실종자

작성일: 2026-11-03

버전: 0.1 / 상태: **채택 검토용 콘텐츠 기획안. 세계관 정사·최종 대본·출시 수치·실제 구현 확정을 뜻하지 않는다.**

상위 기준은 [시나리오·퀘스트·대화 통합 기획안](SCENARIO_QUEST_DIALOGUE_DESIGN.md)이다. 이번 문서는 통합 기획안 D6에 대해 검토할 수 있는 하나의 제안을 선택한 결과다. 미결 질문만 남기는 대신 사건·목표·진입 조건·대사·보상·제작 분량을 연결한다. 채택 여부는 사용자 확인 대상이다.

## 1. 제작 목표와 범위

- 플레이어가 ‘왜 준비하고, 무엇을 조사하며, 누구를 도와야 하는지’를 이해한다.
- 기존 첫 성장 구간의 Training → Intro1 → Intro2 → Intro3 → FirstBoss Normal 흐름을 이야기와 연결한다.
- 기존 Training·Intro1의 승인된 실습 목표를 다른 목표로 덮지 않는다. NPC·조사·추가 사건과 아직 연결되지 않은 A2/A3 콘텐츠는 신규 저작으로 구분한다.
- 메인 8개, 선택 서브 2개, 주요 NPC 4명을 첫 제작 분량으로 제안한다.
- 처음 보는 사람과 완료한 친구가 함께 진행할 수 있고, 반복 입장과 부캐 스킵에서는 긴 대사·귀환 보고를 반복 요구하지 않는다.

가칭과 `CH01.*` ID는 기획 식별자다. 실제 카탈로그·맵 패키지·퀘스트 API에 이미 등록된 값이 아니다. 실존하는 다른 작품의 지역·인물·대사를 재현하는 기획은 아니다.

## 2. 이야기와 인물

광석 운송이 끊기고 조사하러 간 광부들이 돌아오지 않는다. 마을에서는 약탈을 의심하지만, 폐광의 봉쇄 흔적은 안쪽에서 만들어졌다. 생존자의 증언으로 광부들이 채굴 중 깨어난 괴물을 밖으로 나오지 못하게 막았다는 사실을 알게 된다. 플레이어는 준비와 조사를 거쳐 탈출로를 확보하고, 괴물을 제압해 남은 사람들을 구조한다.

결말에서는 채굴·민간 운송을 중단하고 통제된 구조·안전 확보 활동을 이어간다. 다른 갱도에서도 같은 흔적이 발견됐다는 소식으로 다음 챕터의 방향을 제시한다. 첫 챕터의 국소 전술 선택은 이 공통 결말로 합류한다.

| NPC 가칭 | 역할·동기 | 처음과 이후의 변화 | 기능 |
|---|---|---|---|
| 미라 | 운송 담당. 끊긴 길과 마을의 생계를 걱정 | 조속한 재개 요구 → 생존자·안전 우선 | 사건 접수, 귀환 보고, 다음 지역 안내 |
| 로엔 | 교관 겸 구조 준비 담당. 무모한 진입을 막음 | 실력 확인 → 함께 현장을 맡길 동료로 인정 | 기존 실습 안내, 부족한 전투 조건 안내 |
| 다온 | 생존 광부. 남겨둔 동료에 대한 죄책감 | 약탈을 모른 척함 → 봉쇄의 진실과 구조 요청 | 증언, 탈출로·현장 경고 |
| 유나 | 실종자의 가족 대표 | 소식 기다림 → 생존자 맞이·유품 후일담 | 선택 서브·인물 이야기 |

인물 관계 수치 시스템은 이번 제안에 추가하지 않는다. 개인 태도 선택은 필요한 후일담 대사에만 반영하며, 서로 다른 보상이나 필수 해금으로 연결하지 않는다.

## 3. 공간과 콘텐츠 연결

| 공간/경로 | 사용할 기능 | 신규 제작 경계 |
|---|---|---|
| 안전한 준비 거점 | NPC 의뢰·보고·훈련/던전 선택·스킵 | 현재 로비 흐름과 연결할 NPC 화면/상호작용·공간 표현 저작 필요 |
| 훈련 | 기존 기본 공격·회피·돌진·차지 실습 | 기존 목표 유지, 사건을 설명하는 짧은 대화 추가 |
| 폐광 외곽 | 흔적 조사 3개, Intro1 준비·실습 연결 | 조사 지점·서버 상호작용·이동 동선 신규. 완료된 Intro1 실습과 분리 |
| 폐광 안쪽 | A2 공격 기회, 다온 발견, A3 협력·방어 | 목표·사건·연출·맵 연결 신규. 기존 에셋 재사용 가능 여부 확인 필요 |
| 결전 구간 | 기존 FirstBoss Normal 결과·정산 | 기존 보스의 이야기 표현·진입/종료 연출, 내용과 자산의 적합성 확인 |
| 반복 경로 | 기존 훈련·입문·보스의 반복 전투 | 신규 긴 대화·조사 보고 우회, 이번 경로의 목표 인정 범위 표시 |

표의 공간 수만큼 새 맵을 만든다는 뜻은 아니다. 동일 공간의 구역·사건 경로로 묶을 수 있다. 다만 공유 공간의 조사·NPC 상태를 클라이언트만으로 완료시키지 않으며, 실제 서버 권위 경로와 영속 퀘스트 연결은 새 구현 대상이다.

외곽 조사 장소는 조사 의뢰 수락 후 접근할 수 있어야 한다. Intro1 실습 맵 안에 배치하는 경우에는 **Intro1 이야기 입장을 조사 완료로 잠그지 않고**, 조사 완료가 맵 내부의 실습 구간을 연다. 별도 공간으로 작성할 경우에도 조사할 수 없는 공간의 조사 완료를 입장 조건으로 요구하지 않는다.

## 4. 메인 퀘스트 명세

모든 신규 서사 의뢰의 추가 XP·SP·재화·아이템 보상은 이 제안에서 0이다. 성장 보상은 기존 콘텐츠 정산이 소유한다. 서사 의뢰는 진행·인물 반응·이야기 해금을 제공하며, 정산 결과를 읽고 같은 지급을 다시 실행하지 않는다.

| ID / 제목 | 시작·선행 | 목표·수량 | 실패·보존 | 완료 결과·지급 주체 |
|---|---|---|---|---|
| CH01.M01 끊긴 연락 | 미라와 첫 만남, 개인 수락 | 미라·로엔 증언 2개 | 승인 대화 보존. 닫기는 수락/완료 아님 | 준비 안내. 추가 성장 보상 0 |
| CH01.M02 현장에 설 자격 | M01, 로엔 안내 | 기존 Training 성공 1회 | 기존 실습/정산 기준. 임의 캐릭터 클리어 설정 없음 | 실제 Training 정산 XP100, 회전·고유 능력의 기존 습득 규칙 |
| CH01.M03 안쪽에서 남긴 흔적 | M02 뒤 접근 가능한 외곽 | 조사 3개: 파손 수레·안쪽의 봉쇄·생존 흔적 | 승인·저장된 단서 개인 보존. 같은 단서 중복 누적 없음 | 폐광 이야기 조사 단계 충족. 추가 성장 보상 0 |

| CH01.M06 함께 열어야 하는 길 | M05, 실제 Intro2 조건 | Intro3 기여 목표 1회 + 탈출 방어 1구간 | 구출·방어·탈출은 같은 시도 성공 묶음 | 실제 Intro3 정산 XP100·광석2. 일반 보스 이야기 진입 조건 |
| CH01.M07 폐광의 주인 | M06 개인 의뢰 선행, 실제 Intro3 등 기존 입장 조건 | FirstBoss Normal 성공 1회 | 기존 실제 보스 결과·정산·자격 적용 | 실제 보스 정산 XP100·광석4·증표2·기존 개인 추첨. Hard의 기존 전투 해금 |
| CH01.M08 돌아온 사람들 | M07 이야기/개인 보고 자격 | 미라에게 보고 1회, 후일담 선택 | 보고 승인 재시도 동일 처리. 보상 미확정 중 완료 대사 금지 | 챕터 직접 완료·다음 지역 이야기 해금·계정 스킵 자격. 추가 성장 보상 0 |

각 메인은 제시와 개인 수락을 구분한다. M01~M07은 수락 후 정의된 목표가 모두 승인되면 공통 완료 절차로 자동 완료하며, M08은 미라에게 개인 보고한다. 다음 의뢰는 앞선 완료 응답이 확정된 뒤 제시하고 자동 수락하지 않는다. 현장·목표 화면에서도 수락할 수 있게 하여 의뢰마다 거점 귀환을 요구하지 않는다.

M01 수락 승인 뒤 D01의 상황 증언을 첫 근거로 남기고, D02에서 로엔의 준비 설명을 확인한 선택을 두 번째 근거로 남긴다. 두 근거 승인 → M01 완료 확정 → M02 제시·개인 수락 순서다. 단순 소개 열람·창 닫기·훈련 버튼 노출만으로 이 순서를 통과하지 않는다.

M02/M04/M05/M06/M07의 전투 실습 목표는 유효한 기존 완료 영수증을 참조할 수 있다. 의뢰 수락 전에 이미 해당 실습을 완료했다면 본인·콘텐츠·정의 버전·실적을 확인해 인정할 수 있도록 **이 다섯 의뢰의 전투 실습 목표에만 기존 실적 인정 정책을 명시**한다. 일반 처치·단서 전체의 무조건 소급 인정으로 확대하지 않는다.

과거 영수증은 해당 버전·경로가 증명하는 전투 실습만 충족한다. 다온 발견 등 개인 서사 목표는 별도 승인 근거가 필요하며, 같은 시도 구출·방어·탈출을 증명해야 하는 경우에는 전체 묶음의 동일 시도 근거가 있어야 한다. 옛 실습 완료 기록으로 새 서사 사건을 수행했다고 기록하지 않는다. 이미 인정된 기존 실습은 새 서사 추가를 이유로 다시 요구하지 않고, 부족한 서사만 진행할 조사/회상 진입점을 작성한다.

| 구성 | 실제 실습·정산 조건 | 개인 서사 조건·스킵 처리 |
|---|---|---|
| M05 / Intro2 | 승인된 공격 기회 대응 2회 등 해당 버전의 실습 성공 | 다온 발견은 별도 개인 사건. 직접 서사 진행자는 발견 근거가 필요하고, 스킵자는 이 의뢰를 재수행하지 않음 |
| M06 / Intro3 | 기여·방어·생존 탈출의 같은 시도 성공 묶음 | 인물 소개·구출 이유·장면은 서사 경로. 스킵/반복 경로에서도 보호 대상과 실제 방어·탈출 규칙은 유지 |

M05/M06의 새 콘텐츠 목표가 실제로 구현돼 있다는 뜻은 아니다. 기존 목표·정산 경계를 유지하며 별도 에셋·사건·승인 근거를 작성해야 한다. 성공 정산은 해당 버전의 모든 필수 **실습 성공 조건**이 충족됐을 때만 보낸다. 개인 서사 의뢰의 보고 가능 여부와 전투 정산 성공을 별도로 판단하며, 다온 발견·대화 종료가 전투 클리어를 대신하거나 스킵자의 정산을 막지 않는다.

승인 스킵자는 M07 개인 의뢰 대신 별도 실제 보스 진입 경로를 사용한다. 이 경로의 성공은 기존 전투 실적·보상만 갱신하며, 스킵 종료된 M07/M08을 재개하거나 챕터 직접 완료로 바꾸지 않는다.

Hard는 기존 Normal 실제 첫 클리어 조건을 유지한다. M08 귀환 보고를 새 Hard 입장 조건으로 추가하지 않는다. 다른 다음 지역은 아직 정의하지 않았으므로 M08의 해금은 해당 지역이 제작·등록됐을 때 연결한다.

## 5. 신규 목표의 제작 기준

| 목표 | 첫 저작 가설 | 승인 근거·표시 |
|---|---|---|
| 외곽 조사 | 단서 3개, 서로 다른 위치/증언 | 서버 승인 상호작용·고유 단서 ID. 파티 공동 조사를 자격 있는 현장 참가자에게 공유 |
| A2 공격 기회 | 안전한 예고 뒤 열린 공격 기회에서 승인 적중 2회 | 기회 회차별 1회 인정. 회차 밖·죽은 대상·중복 패킷은 제외 |
| A3 기여 | 지정 표적의 현재 시도·세대에서 무력화(Stagger) 누적100 도달 1회 | 부위 파괴(PartBreak)와 합산하지 않음. 이전 시도 완료 재사용 금지. 기존 기여 수신 결과 연결이며 보스 그로기 구현으로 간주하지 않음 |
| A3 방어·탈출 | 45초 후보·2개 웨이브, 생존자 보호 후 붕괴 구역을 벗어나 내부 안전지점 도달 | 같은 시도의 구출·방어·생존 탈출 모두 필요. 실패 시 해당 묶음 재시도. 광산 외부로의 최종 대피는 M07 이후 |

A2의 공격 기회 길이·적 구성, A3의 적 수·생존자 내구도는 전투 제작에서 조정한다. 목표 횟수·시간은 플레이 검증 가설이며 고정 출시 밸런스가 아니다. A3의 45초는 기존 8분 안의 한 구간으로 계획한다.

Training 이전에는 회전·고유 능력을, Intro1 완료 이전에는 도약을 필수 목표로 요구하지 않는다. 기여 목표에는 당시 습득 가능한 차지/도약 등 참여 방법을 제공한다. 특정 트라이포드 선택·고강화를 의뢰 완료 조건으로 강제하지 않는다.

호위를 실제로 이동하는 NPC로 확장할 때에는 이동 실패·전투 이탈·복구 지점 등 별도 구현이 필요하다. 첫 제안은 통합 기획안의 호위 지원 방향을 유지하되 A3의 구체 제작은 고정 위치 방어와 안전한 탈출 구간부터 검토한다.

## 8. 공동 선택과 연출

공동 선택은 A2의 접근로 한 곳에서만 시험한다. ‘정문 돌파 / 배수로 진입’은 다른 진입 동선·짧은 현장 대사를 제공하고, 같은 다온 발견·핵심 보상·메인 결말로 합류한다. 경로 이름·배치는 제작 후보이며 두 개의 완전한 별도 던전 제작을 요구하지 않는다.

투표 후보 규칙은 상위 문서 22절을 따른다. 20초 내 최다 득표, 동률/전원 기권은 미리 표시한 정문 경로다. 개인 표와 실제 채택 경로를 따로 보관한다. 연결 끊김·방장 교체로 이미 확정한 결과를 바꾸지 않는다.

| 장면 | 구성 | 시간 가설 | 반복 경로 |
|---|---|---:|---|
| CH01.C01 보스 등장 | 다온의 경고 → 갱도 진동 → 보스 실루엣 | 14초 | 짧은 현장 경고로 대체 가능하도록 별도 저작 |
| CH01.C02 사건 수습 | 생존자 대피 → 로엔 합류 → 귀환 안내 | 12초 | 정산·복귀 안내로 연결 |

두 장면 모두 준비 대상·기한·실패 경로를 작성하고 개인 스킵은 안전대기로 연결한다. 초행은 기본 감상이며 직접 스킵할 수 있다. 전원 명시적 스킵이 성립하지 않으면 작성된 길이까지 진행한다. 수동 선택 대화의 답을 이 기한으로 자동 선택하지 않는다.

전투 중 “위쪽을 조심하세요” 같은 짧은 말은 입력을 점유하지 않는다. 컷신 길이 26초와 투표 대기 최대20초는 9절의 추가 이야기 시간에 포함해 계산한다.

## 9. 시간·보상·성장 합계

수치는 [첫 성장 구간 수치안](PLAYER_PROGRESSION_FIRST_SLICE_V01.md)의 기존 전투 가설을 기준으로 한다. 실제 플레이 측정 결과가 아니며 훈련·입문·보스의 기존 수치를 이번 문서 작성으로 수정하지 않는다.

신규 Lv1 캐릭터가 위 다섯 콘텐츠를 처음 성공하면 기존 규칙에 따라 누적500XP/Lv6/총14SP다. 서사 의뢰가 같은 XP500을 다시 지급하지 않는다. 광석10·증표2는 소비 전 누적 지급량이다. 보스의 개인 장비 추첨은 기존20%·4종 균등 가설을 유지하므로 각 종류의 클리어당 확률은5%이며, 장비가 반드시 하나 나오는 경로가 아니다.

서브의 전투 성장 지급0은 이 제안의 선택이다. 인물 이야기와 기록을 보상으로 삼은 구성이 실제로 매력적인지 플레이 검토하고, 보상을 바꿀 때에는 성장 시간·선택성·스킵 정책을 함께 다시 계산한다.

## 10. 부캐·반복·혼합 진도

스토리를 건너뛴 부캐는 M01~M08의 이야기 선행을 충족하지만 기존 Training→Intro1→Intro2→Intro3의 **실제 실습 조건은 유지**한다. 부캐 화면은 ‘이야기 해금 완료’와 ‘현재 남은 실습 조건’을 별도로 표시한다. 실제 실습 성공마다 기존 정산 XP100·원래 재료를 지급하고, 스킵 자체는 XP·재화·장비를 지급하지 않는 안이다.

직접 완료 이후 일반 현장 방문은 잔류 위협 정리·구조와 안전 확보를 목적으로 안내한다. 이미 구조된 인물을 다시 실종자로 소개하지 않는다. 기존 보스를 같은 조건으로 다시 공략하는 메뉴는 ‘완료한 전투 다시하기’로 표시하며, 사건 시간선을 되돌리거나 같은 괴물이 부활했다고 기록하지 않는다. 전투 보상은 기존 반복 규칙을 따른다.

실습 진입은 긴 사건 대화·서사 조사·귀환 보고를 다시 요구하지 않는 직접 경로로 제공한다. 기존 Intro1의 실제 접근·회전 목표 등 실습 자체는 수행한다. 최초 실제 Normal 클리어 후 Hard가 열리는 조건도 그대로다. 스킵만으로 기존 성장 milestone을 세우거나, Training+Intro1만 마친 캐릭터가 Normal에 입장·정산할 수 있다고 가정하지 않는다.

이미 실습을 끝낸 부캐에게는 그 실적을 보존하며 중복 강제하지 않는다. 개인 전투력·SP·장비는 직접 얻은 상태 그대로다. 현재 첫 구간에는 새로운 장비 점수 하드게이트를 추가하지 않는다.

처음 보는 A, 완료한 B, 다른 단계 C가 함께 진행한다면 출발 화면에서 이야기/반복 경로와 진행 가능한 개인 목표를 표시한다. 핵심 조사·구출 사건이 필요한 사람이 있는 이야기 경로에서는 B의 완료 이력으로 문·NPC·사건을 생략하지 않는다. 반복 경로에 없는 사건의 달성을 클리어 결과만으로 대신 인정하지 않는다.

스킵자도 초행 친구의 이야기 경로에 동행해 장면을 감상할 수 있다. 감상이 이미 기록된 스킵을 직접 완료로 바꾸거나 최초 보상을 되살리지는 않는다. 자신에게 유효한 실제 실습·던전 보상은 기존 규칙대로 별도 처리한다.

| 분류 | 이번 제안 분량 | 작업 |
|---|---|---|

| 대화 | 핵심 노드12 + 정보/태도/서브 후속 | 텍스트 저작, 조건·선택·진입점, 번역 키 |

## 12. 플레이 검토와 채택 판단

| 검토 | 통과 기준 |
|---|---|
| 초행자 | 개발자 설명 없이 사건 이유·현재 목표·다음 목적지를 이해 |
| 필수 실습 | 해금되지 않은 스킬 요구 없음, 기존 Training/Intro1 동작 보존 |
| 시간 | 기본 빌드까지 목표40분, 메인55분 가설과 실제 편차·추가 대기 측정 |
| 협동 | 완료자 동행으로 초행의 필수 사건이 소실되지 않고 불필요한 개별 클릭 대기 최소화 |
| 선택·연출 | 표와 채택 결과 구분, 초행 기본 감상·개인 스킵 안전대기, 무한 준비 대기 없음 |

| 부캐 | 스킵 직후 성장치 불변, 실습/반복 진입 유지, 이미 한 실습 재강제 없음 |
