# 대검 전사 아이덴티티 회의와 폭주 설계안

회의일: 2026-11-02

**일반 상태에서 투지를 모으고, 폭주에 진입하면 현재 퀵슬롯의 분노 스킬 쿨타임을 초기화한다. 폭주 중 분노 스킬을 사용할 때마다 강화 피해를 주고 투지를 소비하며, 시간이 지나도 투지는 감소하지 않는다. 투지를 소진하면 폭주를 끝내고 다시 모은다.** 사용자의 최종 설명을 기준으로 앞선 5명이 재검토한 설계다.

`투지`, `아덴 게이지`, 대화의 `분노/폭주 게이지`는 여기서 하나의 자원을 뜻한다. 일반 스킬과 분노 스킬은 기술 분류이고, 일반 상태와 폭주 상태는 캐릭터 상태다. 분노 스킬이라는 이름이 폭주 중에만 사용할 수 있다는 뜻은 아니다.

사용자 확정 구조와 기획팀의 제안 수치를 구분한다. **첫 비교안은 최대 100, 100에서 진입, 분노 스킬 사용 승인당 50 소비, 피해 +15%이며 +25%를 대조안으로 둔다.** 횟수를 두 번으로 제한한 규칙이 아니라 이 비용으로 계산되는 사용량이다. 게임 코드·에셋에는 아직 적용하지 않았다.

## 1. 사용자 방향과 회의 결론

| 사용자 최종 방향 | 적용할 의미 |
|---|---|
| 일반/분노 스킬 구분 | 분노 스킬만 폭주 중 소비·강화 대상 |
| 퀵슬롯에 등록된 스킬 대상 | 진입 시 현재 등록된 분노 스킬의 쿨타임 초기화. 미등록 보유 스킬 제외 |
| 폭주 중 분노 스킬 사용 시 게이지 소모 | 승인된 매 시전의 강화와 비용. 첫 한 번만 강화하는 구조 아님 |
| 모든 분노 스킬은 스킬 사용 1회당 소비 | 회전도 같은 규칙. 유지 시간·회전 주기·타격 횟수·맞힌 적 수에 따른 추가 소비 없음 |
| 자연 감소 없음 | 대기·이동·회피·일반 스킬 사용으로 투지가 줄지 않음. 폭주 지속시간 없음 |
| 소진 후 종료·재수급 | 남은 투지가 있는 동안 운용하고 0이면 일반 상태로 복귀 |

같은 분노 스킬도 정상 쿨타임이 돌아오고 투지가 충분하면 재사용하는 안을 채택했다. 슬롯별 1회 제한은 없다. 초기 회의의 12초 시간제 폭주와 일괄 후딜 단축은 현재 권고안에서 제외한다. 이전 대화의 ‘첫 1회 사용 후 전체 종료’ 해석도 사용자의 최종 설명으로 바로잡았다.

2026-11-02 후속 사용자 결정: “그냥 스킬 하나당으로 하자”. 소비 단위는 모든 분노 스킬에 공통으로 **스킬 사용 1회당 한 번** 적용한다. 회전의 주기별·유지 중 분할 소비 대안은 채택하지 않는다. 회전을 종료하고 다시 사용하면 새 사용이므로 다시 비용을 낸다. 이 결정은 소비 단위를 확정한 것이며, 스킬당 50 등의 실제 소모량과 강화율은 여전히 비교용 제안이다.

| 동일 참가자 | 최종 의견과 교차 검토 |
|---|---|
| 직업 디렉터 `class_director` | 사용 시점을 기다리고 공격에 자원을 배분하는 버서커로 정리. 일반 상태의 분노 스킬 사용·동일 기술 재사용 허용 |
| 전투 조작 `combat_designer` | 승인 시 비용·강화 확정, 부분 차지도 강화, 회전은 시전당 한 번 소비. 피해 25% 초안에서 15% 기준/25% 대조로 조정 |
| 애니메이션·연출 `animation_designer` | 타이머 제거, 등록된 분노 슬롯에만 초기화·강화 표시, 마지막 시전의 강화 표현 유지. 수동 해제 오입력 경계 지적 |
| 밸런스 `balance_designer` | 쿨타임 초기화의 추가 공격이 핵심 위력. 공통 비용 50·피해 15% 기준 권고, 미소비 초기화 스킬의 후속 피해까지 계산 |
| 성장·학습 `progression_designer` | 차지만 등록한 초반 편성도 허용. 습득과 자동 편성을 구분. 수동 종료는 필수로 가르치지 않는 의견 |

개별 제안 후 수치·비용 확정 시점·표현·초기 편성 사례를 서로 전달하고 디렉터와 조작 담당이 통합안을 다시 검토했다. 수동 해제의 필요성에는 의견 차이가 있어 선택적 보조 조작으로 제안하고, 핵심 학습 과정에서는 제외한다.

## 2. 첫 비교용 규칙

아래의 수급량·진입 조건·소모량·강화율·수동 해제는 기획팀 제안이다. 사용자 확정 수치 또는 플레이 검증 결과가 아니다.

| 항목 | 첫 비교안 |
|---|---|
| 최대 투지·진입 조건 | 100. 만충 때 수동 발동, 자동 진입 없음 |
| 진입 비용 | 진입 때는 100 유지. 이후 분노 스킬 사용에 나누어 소비 |
| 일반 상태 수급 | 기본 연계 전체 적중·완주 10, 유효한 스킬 적중은 시전당 20. 일반 상태에서 사용하는 분노 스킬도 수급 가능 |
| 중복 수급 | 같은 시전의 다단·다수 적중으로 추가 지급하지 않음 |
| 폭주 중 수급 | 기본 공격·일반 스킬·분노 스킬 모두 0. 뒤늦은 보상이나 보관 수급 없음 |
| 분노 스킬 비용 | 모든 분노 스킬의 사용 승인당 한 번 소비. 첫 비교값은 50이며 회전도 유지·타격에 따른 추가 소비 없음 |
| 강화 피해 | 해당 시전의 기본 피해 ×1.15. ×1.25는 별도 대조안 |
| 다른 성능 | 기본 공격·일반 스킬의 피해, 이동속도·공격속도·후딜·방어·무력화·파괴는 폭주 때문에 증가하지 않음 |
| 쿨타임 | 진입 때 대상 기술의 남은 쿨타임을 1회 초기화. 이후 사용하면 정상 쿨타임 시작 |
| 재입력 | 폭주 중 짧은 재입력은 초기화·재충전·해제 모두 하지 않음 |
| 자연 종료 | 투지 0에서 종료. 마지막 승인 시전의 강화와 수급 금지는 끝까지 유지 |

시간 제한이 없는 대신, 폭주를 켠 채 기다리는 것만으로 일반 공격·방어의 상시 이득은 생기지 않는다. 폭주를 오래 유지하면 다음 투지를 모으는 시점도 늦어진다. 기다렸다 같은 분노 스킬을 다시 쓸지, 다른 분노 스킬을 이어 쓰고 재수급을 시작할지가 선택이다.

피격을 받아 투지를 얻는 규칙, 저체력 보너스·흡혈·체력 소모·상시 면역은 추가하지 않는다. 계수와 수급이 검증되기 전 장비로 폭주 중 수급을 열거나 무료 분노 시전을 부여하지 않는다.

## 3. 스킬 분류와 실제 사용 예시

사용자 선택에 따라 현재 임시 제작 범위는 아래 중심 4종이다. [직업 회의의 임시 범위](GREATSWORD_WARRIOR_DESIGN_MEETING_20261102.md)를 기준으로 일반 2종·분노 2종의 분류안과 아이덴티티 순환을 먼저 검증한다. 확장 후보 4종의 제작·분류는 후순위로 둔다.

| 첫 중심 스킬 | 분류 제안 | 일반 상태 | 폭주 상태 |
|---|---|---|---|
| 돌진 베기 `AssultBlade` | 일반 | 기존 접근·피해·쿨타임, 적중 시 수급 | 기본 성능 유지. 투지 소비·획득 없음 |
| 도약 강타 `JumpSmash` | 일반 | 기존 범위·기여·쿨타임, 적중 시 수급 | 기본 성능 유지. 투지 소비·획득 없음 |
| 차지 슬래시 `ChargeSlash` | 분노 | 기존 차지·피해·쿨타임, 적중 시 수급 | 승인당 50 소비, 해당 차지 피해 강화. 허용된 부분 해제에도 동일 배율 |
| 회전 베기 `WhirlWind` | 분노 | 기존 유지·피해·쿨타임, 시전당 수급 | 승인당 50 한 번 소비, 승인된 전체 타격 강화 |

분류는 명시적인 스킬 데이터로 다룬다. 이름에 Charge/Rage가 있거나 차지 방식으로 실행된다는 이유만으로 분노 스킬로 자동 분류하지 않는다. 추가 후보의 분류와 비용은 아직 정하지 않았다.

**혼합 사용 예시:** 투지 100에서 일반 차지·회전을 사용해 쿨타임에 들어감 → 폭주 진입으로 등록된 두 스킬 쿨타임 초기화, 투지 100 유지 → 강화 차지 승인으로 50 → 적의 공격을 회피하고 돌진으로 위치 변경, 투지 50 유지 → 강화 회전 승인으로 0·폭주 종료 → 회전은 끝까지 강화되고 투지는 주지 않음 → 다음 일반 상태 행동으로 재수급.

이 예시는 사용자가 원하는 주력기 사용 후 다시 강하게 사용하는 리듬이다. 모든 기술을 반드시 소모한 뒤에만 폭주를 켜도록 강제하지 않는다. 공격 기회와 현재 쿨타임에 따라 바로 켜는 선택도 가능하다.

**동일 기술 사용 예시:** 차지만 등록된 상태에서 폭주 → 강화 차지로 50 → 차지의 정상 쿨타임을 기다리며 일반 공격·이동·회피 → 다시 강화 차지로 0. 중간에 자동 종료하거나 두 번째 차지를 금지하지 않는다. 회전만 등록한 경우도 같은 원칙이다.

분노 스킬이 하나도 등록되지 않은 편성에서는 진입 전에 거절하고 등록을 안내한다. 습득한 회전을 자동 편성하거나 플레이어의 슬롯을 바꾸지 않는다.

## 4. 진입과 쿨타임 초기화

진입은 생존·대검 장착·아이덴티티 해금·현재 전투 권한·투지 100·유효한 분노 스킬 1개 이상 등록을 확인한 뒤 승인한다. 첫 시제품은 공격·차지·회전·회피·피격 제어 중에는 진입을 거절한다. 현재 행동이 끝난 뒤 새 입력으로 발동하며, 실패한 입력을 오래 예약했다가 뒤늦게 자동 발동하지 않는다.

초기화 대상은 승인 시점에 서버가 확인한 현재 퀵슬롯의 분노 스킬이다. 같은 스킬 ID가 중복 참조돼도 한 번만 처리한다. 미등록 스킬, 일반 스킬, 기본 회피, 고유 능력 및 그 밖의 공통 쿨타임에는 영향을 주지 않는다. 쿨타임 초기화는 피격·행동 제한을 해제하거나 사망한 기술을 사용할 권한을 주지 않는다.

분노 스킬의 사용 쿨타임은 매번 정상적으로 시작한다. ‘폭주 중 항상 쿨타임 0’으로 구현하지 않는다. 서버 진입 사건에 한 번만 초기화를 묶어 연타·중복 요청·재접속으로 반복하지 않는다. 스킬들이 하나의 쿨타임 효과를 공유한다면 다른 기술의 쿨타임까지 삭제하지 않도록 적용 범위를 먼저 분리해야 한다.

전투 중 편성 변경은 기존 금지 규칙을 유지한다. 폭주 중 다른 스킬을 새로 등록해 초기화 대상을 늘리는 동작은 허용하지 않는다. 8개 편성으로 확장하더라도 ‘처음 쓴 두 기술만 초기화’나 ‘스킬당 한 번만 사용’으로 사용자 규칙을 바꾸지 않는다.

## 5. 소비와 종료의 정확한 경계

| 사건 | 자원·공격 결과 |
|---|---|
| 승인 전 조준 취소, 비용·대상·자격 실패 | 투지와 새 쿨타임 소비 없음 |
| 유효한 분노 스킬 사용 승인 | 비용·쿨타임·강화 사양을 한 번 확정한 뒤 공격 시작 |
| 승인 후 취소·피격 중단·빗나감 | 투지·쿨타임 비환급. 아직 발생하지 않은 타격은 기존 취소 규칙에 따라 중단 |
| 부분 차지 | 해당 변형에서 허용하는 부분 피해에 같은 강화 배율. 완충 피해로 바꾸지 않음 |
| 회전 다단·여러 적 | 비용은 시전당 한 번. 해당 시전의 유효한 타격마다 동일 강화 배율 |
| 마지막 비용으로 0 | 캐릭터는 일반 상태가 되지만 마지막 시전의 강화·수급 0은 종료까지 고정 |
| 회전 종료타 | 원래 정상 종료 조건을 만족할 때만 발생. 게이지 0이나 강제 중단을 이유로 새 막타를 생성하지 않음 |
| 폭주 중 회피·대기·일반 스킬 | 투지 유지. 기존 제어·취소·피해 규칙은 그대로 |
| 사망·전투 권한 회수 | 폭주·투지 회수. 남은 강화 시전도 기존 사망/취소 규칙에 따라 종료 |
| 동일 전투 시도의 재접속 | 서버의 상태·게이지·쿨타임을 기준으로 복원. 재접속을 새 폭주 진입 사건으로 처리하지 않음 |
| 서버가 확정한 새 전투 시도 | 기존 새 시도 초기화 계약 적용. 단순 재접속·UI 조작과 구분 |

게이지가 0이 된 뒤에도 마지막 강화 공격이 수급을 시작하지 않도록, **폭주 중 승인한 시전은 끝까지 수급 금지**를 함께 고정한다. 폭주 중에 적중한 과거 시전의 수급을 나중에 돌려주지도 않는다. 이후 일반 상태에서 새로 승인한 행동부터 정상 수급한다. 승인·소모·강화 고정은 서버에서 하나의 결과로 처리하여 비용만 내거나 강화만 얻는 중간 상태를 노출하지 않는다.

개별 스킬의 최대 유지시간·적중 횟수·종료 조건은 유지한다. 폭주 자체의 시간 제한이 없다는 이유로 회전 한 번을 영구 유지하거나 무제한 타격하도록 바꾸지 않는다.

### 선택적인 수동 해제

디렉터·조작 담당은 잔여 투지를 버리고 일반 상태로 돌아오는 선택을 권했고, 학습·연출 담당은 핵심 조작으로 요구하지 말고 오입력을 막아야 한다는 의견을 냈다. 첫 검토안은 **발동 키를 완전히 놓은 뒤, 행동 중이 아닐 때 새로 0.6초 길게 눌러 해제**하는 보조 조작이다. 0.6초는 사용성 시험값이다.

누르기 시작과 완료 때 모두 행동 가능해야 한다. 도중 공격·회피·피격이 시작되거나 일찍 놓으면 해제 시도만 취소하고 현재 상태를 유지한다. 성공 때만 잔여 투지 전부 포기·폭주 종료하며, 현재 스킬을 취소하거나 쿨타임을 다시 초기화하지 않는다. 다시 폭주하려면 일반 상태에서 100을 모아야 한다.

길게 누르는 동안 ‘종료하면 남은 투지 소멸’을 표시한다. 기본 훈련에서 이 조작을 필수로 요구하지 않는다. 로비 복귀·무기/직업 교체처럼 폭주 자격이 없어지는 전환은 잔여 투지를 환급하지 않고 상태를 정리하는 안으로 두며, 실제 수명 계약을 연결할 때 해당 사건을 명시한다.

## 6. 수치 선택과 밸런스 쟁점

공통 비용 50은 첫 비교를 단순하게 만든다. 차지 60·회전 40부터 시작하면 차지 두 번은 불가능하고 회전 두 번 뒤에는 20이 남아 별도 잔여 처리 규칙이 필요하다. 첫 비교에서는 두 기술 모두 50으로 두고 선택 이유·적중률·쿨타임 대기를 확인한다. 향후 비용을 바꿀 때에는 남은 게이지로 아무 기술도 쓸 수 없는 상태를 함께 설계해야 한다.

기존 첫 구간 피해 가설인 차지 2.8·회전 2.4를 사용한 다음 계산은 **충분한 공격 시간과 전타 적중, 비교 구간 안에 자연 쿨타임이 돌아오지 않는 조건**의 공격력 배수 합이다. 실제 DPS나 애니메이션 실측이 아니다.

| 비교 | 피해 합 |
|---|---:|
| 일반 차지·회전 한 번씩 | 2.8 + 2.4 = 5.2 |
| 위 공격 후 초기화·강화 두 기술, 강화 15% | 5.2 + 5.2×1.15 = 11.18 |
| 같은 구성, 강화 25% | 5.2 + 5.2×1.25 = 11.70 |

따라서 강화율만 보고 위력을 평가할 수 없다. 추가 시전 기회를 주는 쿨타임 초기화가 큰 비중을 차지한다. 첫 기준은 +15%, 조작 담당의 +25%는 대조로 두고, 모션과 실제 재충전까지 포함해 비교한다. 기존의 한 번 강화 +25%와 새안의 +25%는 같은 총성능이 아니다.

같은 비용에서 차지만 두 번 쓰면 강화 피해 합은 6.44, 차지·회전 혼합은 5.98이지만 차지 반복에는 정상 쿨타임 대기가 필요하다. 그동안 다음 투지를 모을 수 없다. 이 차이를 선택으로 남기고, 모든 상황에서 같은 기술 반복이 유리하다면 스킬의 기회 적합성·기본 계수·비용을 조정한다.

분노 스킬 4개를 모두 초기화한 뒤 2개로 소진하면 나머지 2개의 초기화 이득은 일반 상태에도 남는다. 이는 현재 사용자 규칙에 따른 결과다. 그 쿨타임을 임의로 되돌리거나 초기화 대상을 2개로 바꾸지 않고, **강화하지 않은 기술의 빠른 재사용까지 포함해** 평가한다. 분노 스킬만 편성하는 구성이 일반 스킬의 접근·기여·수급 역할을 완전히 대체하는지도 확인한다.

앞선 시간제 폭주에서 계산한 30~37초 주기·32~40% 가동률 목표는 이 안에 이식하지 않는다. 대기 시간은 플레이어가 선택하며, 새 안은 한 충전의 추가 피해·소비 완료까지의 시간·재수급 주기를 측정한다.

## 7. 화면과 보유 에셋 활용

| 만충 | ‘폭주 준비’와 현재 재지정 키. 자동 감소·조급한 타이머 없음 |

| 기술 선택·준비 | 투지바에 예정 소비 구간 표시. 실제 승인 때만 차감 연출 |
| 마지막 사용으로 0 | 몸의 폭주 효과는 종료. 진행 중 마지막 공격의 무기·스킬 강화 표식은 종료/중단까지 유지 |

기존 파일·참조 조사에서 확인한 후보는 다음과 같다. 모션 길이·동작 적합성·밝기와 화면 가림은 직접 재생해 확인하지 않았다.

폭주를 무기 주변의 낮은 강도 효과로 유지하고, 분노 스킬 사용에 강한 소리와 궤적을 집중한다. 시간 제한 없이 유지할 수 있으므로 지속적인 전체 화면 색조·흔들림·반복 포효를 기본 연출로 넣지 않는다. 보스 예고선과 4인 교전의 시야를 우선 확인한다.

## 8. 학습과 검증 계획

기존처럼 기본 훈련 완료 후 회전·아이덴티티를 해금한다. 최초 네 조작 목표에 폭주를 추가하지 않는다. 해금 안내는 ‘분노 스킬을 사용한 뒤 폭주로 다시 준비 → 강화 공격에 투지 소비 → 소진 후 다시 모으기’를 가르친다. 습득한 회전이 자동 편성되지 않을 수 있으므로 차지 하나만 등록한 사례도 정상이다.

선택 연습에서는 회피·대기로 투지가 줄지 않는 것, 일반 스킬은 폭주 중 소비하지 않는 것, 같은 분노 스킬도 정상 쿨타임 후 다시 쓸 수 있는 것을 확인한다. 두 종류의 분노 스킬을 반드시 사용하거나 제한 시간 안에 모두 털어야 하는 과제는 만들지 않는다.

| 후속 비교 | 확인할 기준 |
|---|---|
| 현재 1회 강화와 새안 | 같은 장비·투지 0 시작의 60초/180초, 실제 공격·재수급 포함 피해 |
| 강화 15%와 25% | 초기화로 추가된 시전과 강화 자체의 피해를 분리 집계 |
| 같은 기술 반복과 혼합 | 폭주 유지·대기·소비 완료·다음 진입까지 시간, 이동/정지 적별 선택 |
| 쿨타임 초기화 | 전부 준비/일부 대기/전부 대기, 중복 요청·재입력·미등록 스킬 영향 없음 |
| 자원 경계 | 승인 전 취소, 승인 후 취소·빗나감, 회전 다단, 마지막 시전 강화·수급 0 |
| 0개/1개/2개 이상 분노 편성 | 진입 안내, 차지 단독 정상 순환, 확장 시 미소비 초기화 기술의 일반 피해 |
| 학습·표현 | 시간 감소가 없음을 이해, 쿨초와 행동 제한 구별, 마지막 공격이 강화됨을 인지 |
| 멀티플레이 | 소유자·관찰자 상태 일치, 4인 동시 폭주 시 피해·기여·시야, 사망/재접속 중 중복 초기화 없음 |

이 표는 계획이며 실행 결과가 아니다. 자연 감소와 사용 횟수 제한을 넣어 문제를 덮지 않고, 스킬의 비용·성능·일반 스킬 역할을 먼저 조정한다.

## 9. 현재 구현과 후속 인계

현재 [Resolve Ability](../Source/Project_RPG/Private/Ability/Skill/RPGGreatSwordResolveAbility.cpp)는 진입 때 100을 소비하고 10초 안의 다음 적격 차지·회전 한 번을 1.25로 강화한다. [SkillContainer](../Source/Project_RPG/Private/Skill/RPGGameplayAbility_SkillContainer.cpp)는 승인 시 그 강화 기회를 소비하고 해당 시전에 고정한다. 새 설계의 진입 유지·사용별 소비·편성 대상 쿨초·자연 감소 없는 상태는 이번 회의에서 구현하지 않았다.

기존 [일반 Ability](../Source/Project_RPG/Private/Ability/RPGPlayerGameplayAbility.cpp)의 `GainIdentity`는 현재 Resolve 설정이면 옛 수급 경로를 건너뛴다. 예전 Rage 속성·태그나 폭주 이름의 몽타주가 있다는 사실만으로 새 설계가 이미 연결됐다고 간주하지 않는다.

후속 구현은 스킬의 일반/분노 분류·비용, 현재 퀵슬롯에서의 초기화 대상 조회, 폭주 상태 수명, 사용 승인과 비용·강화 고정, 수급 차단, UI를 각각 기존 책임에 연결해야 한다. 같은 자원이나 현재 편성을 다른 컴포넌트에 중복 저장하지 않는다. 사망·재접속·무기/직업 교체는 기존 소유권·전투 시도 계약과 함께 설계한다.

상위 참고는 [대검 직업 회의](GREATSWORD_WARRIOR_DESIGN_MEETING_20261102.md), [첫 구간의 현재 계약](PLAYER_PROGRESSION_FIRST_SLICE_V01.md), [스킬 아키텍처](SKILL_AND_TRIPOD_MODULAR_ARCHITECTURE.md), [기존 훈련 안내](PLAYER_PROGRESSION_TRAINING_GUIDE.md)다. 새 설계가 승인·구현되기 전까지 기존 문서의 운영 수치를 이미 변경한 것으로 취급하지 않는다.

최종 문서에서 밸런스 담당이 사용자 규칙·수치·산술을 재검토했고, 고유 능력 자체의 쿨타임은 초기화 대상이 아님을 문장에 명확히 반영했다. 이 문서와 기존 회의 문서의 상대 링크 각 11개 존재·본문 공백을 확인했다. 문서 검사이며 게임 실행 검증이 아니다.

회의 산출물은 이 문서와 기존 회의의 후속 링크다. 공유 소스·에셋·빌드·UE 실행·DB 변경 없음. 임시 생성/삭제 0 bytes, 정리 예외 없음. 에셋 직접 재생과 플레이 밸런스 검증은 후속 단계다.
