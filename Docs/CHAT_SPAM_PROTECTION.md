# 로비 채팅 도배 방지

로비 일반과 던전에서도 사용할 수 있는 귓속말에는 Steam 계정 기준으로 최소 전송 간격 0.5초와 최근 10초 동안 총 8건 한도를 적용한다. 로비 일반은 별도로 최근 10초에 3건까지 전송할 수 있고, 귓속말은 같은 수신 캐릭터에게 최근 10초에 4건까지 전송할 수 있다.

로비 일반은 같은 문구를 20초 후, 귓속말은 같은 수신 캐릭터에게 같은 문구를 3초 후 다시 보낼 수 있다. 비교할 때는 유니코드 NFC, 대소문자 무시, 앞뒤 공백 제거 및 연속 공백 축소를 적용한다. 표시 본문에는 비교용 변환을 적용하지 않는다. 예를 들어 `파티 구해요`와 `파티  구해요`는 같은 문구로 판정한다.

제한 이력은 백엔드 프로세스 메모리에 유지하며 캐릭터 변경과 채팅 재접속을 거쳐도 유효 기간까지 유지한다. 전송에 성공한 메시지만 이력에 기록한다. 이미 수락한 요청 ID의 동일 요청은 기존 영수증이 유효한 동안 다시 방송하거나 전송 횟수를 소비하지 않는다.

서버가 제한을 적용하면 HTTP 429에 `chat_duplicate` 또는 `chat_rate_limited`와 초 단위 `retryAfterSeconds`를 반환한다. 여러 제한이 동시에 적용되면 가장 긴 대기를 알려준다. 발신자의 입력은 남고 발신자에게만 안내를 표시한다.
