# 플레이어 미니맵

`/Game/Maps/RegionTravel/L_Town`을 열고 플레이하면 우편 버튼 아래에 미니맵이 표시된다. 미니맵은 DPI 적용 전 280×280이며, 이 맵의 퀘스트 안내는 미니맵 아래에 표시된다. 내 캐릭터를 중심으로 수평 반경 12m 안의 지형만 표시한다. 중앙의 파란 화살표는 캐릭터 방향을 따라 회전하고, 이동하면 주변 지형이 갱신된다. 녹색 이동 문 아이콘은 반경 안에 들어오면 나타난다. 마을과 필드를 오갈 때 도착한 지역의 지형과 문을 사용한다.

`T_TownMinimap`은 월드 원점을 중심으로 두 축의 ±1,800cm 안에 있는 광장과 건물을 표시한다. `T_FieldMinimap`은 월드 (55,400, 0)cm를 중심으로 두 축의 ±7,800cm를 담는다. 귀환 문에서 교역소와 숲길을 거쳐 폐성당으로 가는 길을 확인할 수 있다. +X는 위, +Y는 오른쪽이다. `L_Town`에서 스트리밍된 필드와 온라인 이동으로 도착하는 `L_PortalField` 모두에서 로컬 Pawn의 위치에 맞는 지도를 고른다. 문은 퍼시스턴트 레벨에 배치된 `RPGRegionGate`의 실제 좌표로 표시한다.

`WBP_PlayerHUD`의 로컬 빙의 수명에 맞춰 네이티브 위젯을 부착한다. `/Game/Minimap`의 프레임·화살표·포털 아이콘은 GladiatorCore에서 가져온 텍스처이며, `PAL_TownMinimap`이 런타임 로드용 패키지의 쿠킹을 지정한다.

필드에서 Tab을 누르면 전체 지도가 열리고, 다시 누르거나 마을로 돌아오면 닫힌다. 스트리밍 필드는 포털의 도착 화살표를, `L_PortalField`는 입장용 PlayerStart를 검사 시작점으로 사용한다. 캐릭터의 캡슐 크기와 걸을 수 있는 경사·턱 높이를 사용해 고정 지형의 통행 가능 영역을 약 1m 간격으로 검사한다. 이어지는 길과 공터를 반투명 회색 면과 어두운 윤곽선으로 게임 화면에 겹쳐 그린다. 연결되지 않은 지형, 점프로만 닿는 지형, 조사한 범위 밖은 투명하다.

히든 루트는 필드 또는 퍼시스턴트 레벨에 `Trigger Box`를 배치하고 Details의 **Actor Tags**에 `Minimap.HiddenRoute`를 추가해 지정한다. 통로의 폭과 높이 전체를 감싸고, 충돌 프리셋은 `NoCollision`으로 설정한다. 박스에 걸치는 지도 셀과 숨김 구역 안의 플레이어·포털 아이콘을 그리지 않는다. 공개 진입점에서 숨김 구역을 거쳐야만 닿을 수 있는 공간도 제외된다.

폭이 한 셀인 막다른 끝은 지도에서 최대 두 셀까지 덜어낸다. 양쪽이 이어지는 좁은 통로와 포털 도착 셀은 표시한다. 이동 가능 영역에 둘러싸인 가로·세로 최대 두 셀의 작은 구멍은 지도에서 메운다. 나무나 작은 소품 주변의 표시를 정리하면서 이동 가능 영역의 바깥 경계와 히든 루트는 그대로 반영한다.

처음 Tab을 누르면 지도 준비 안내가 즉시 표시된다. 필드가 스트리밍되면 전체 지도를 프레임에 나눠 계산한다. 준비 중에도 Tab으로 닫을 수 있고, 다시 열면 계산을 이어서 진행한다. 계산이 끝난 지도는 같은 로드 상태에서 바로 다시 열린다. 닫혀 있는 지도는 그리기와 틱을 건너뛴다. 캐릭터 이동을 따라가는 우측 상단 미니맵은 위의 지역별 텍스처를 쓴다.
