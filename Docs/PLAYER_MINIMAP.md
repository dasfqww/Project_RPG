# 플레이어 미니맵

`/Game/Maps/RegionTravel/L_Town`을 열고 플레이하면 우측 상단의 우편 버튼 아래에 미니맵이 표시된다. 미니맵은 DPI 적용 전 280×280이며, 이 맵의 퀘스트 안내에는 미니맵 아래 위치를 사용한다. 파란 화살표는 내 캐릭터의 위치와 방향을, 녹색 아이콘은 현재 지역의 이동 문을 가리킨다. 필드에 도착하면 필드 지도와 마을 귀환 문을, 마을로 돌아오면 광장 지도와 필드 입구를 표시한다.

지도 이미지는 각 중심에서 두 축으로 ±1,800cm를 담는다. `T_TownMinimap`의 중심은 월드 원점이며 광장·건물·문 기둥을 담는다. `T_FieldMinimap`의 중심은 월드 (50,000, 0)cm이며 필드 바닥, 지형 표식, 귀환 문 기둥을 담는다. +X는 위, +Y는 오른쪽이다. 두 지역은 같은 퍼시스턴트 월드에 있으므로 로컬 Pawn이 도착한 위치로 사용할 지도를 고른다. 문은 퍼시스턴트 레벨에 배치된 `RPGRegionGate`의 Region Level 설정과 실제 좌표로 표시한다.

`WBP_PlayerHUD`의 로컬 빙의 수명에 맞춰 네이티브 위젯을 부착한다. `/Game/Minimap`의 프레임·화살표·포털 아이콘은 GladiatorCore에서 가져온 텍스처이며, `PAL_TownMinimap`이 런타임 로드용 패키지의 쿠킹을 지정한다.
