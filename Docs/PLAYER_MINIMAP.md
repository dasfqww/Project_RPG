# 플레이어 미니맵

`/Game/Maps/RegionTravel/L_Town`을 열고 플레이하면 좌측 상단에 미니맵이 표시된다. 내 캐릭터의 화살표는 위치와 바라보는 방향을 따르고, 녹색 아이콘은 필드로 이어지는 지역 이동 문을 가리킨다. 필드로 나가면 지도는 숨고 마을로 돌아오면 다시 보인다.

지도 이미지 `T_TownMinimap`은 마을 광장·건물·문 기둥의 배치를 위에서 본 평면도다. 중앙은 월드 원점이고 각 축의 범위는 −1,800~+1,800cm다. +X는 위, +Y는 오른쪽이다. 지형을 수정하는 경우 이 범위와 방향으로 이미지를 다시 그린다. 아이콘 위치에는 해당 Pawn과 퍼시스턴트 레벨에 배치된 `RPGRegionGate`의 좌표를 사용한다.

`WBP_PlayerHUD`의 로컬 빙의 수명에 맞춰 네이티브 위젯을 부착한다. `/Game/Minimap`의 프레임·화살표·포털 아이콘은 GladiatorCore에서 가져온 텍스처이며, `PAL_TownMinimap`이 런타임 로드용 패키지의 쿠킹을 지정한다.
