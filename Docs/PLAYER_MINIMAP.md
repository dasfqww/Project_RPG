# 플레이어 미니맵

`/Game/Maps/RegionTravel/L_Town`을 열고 플레이하면 우편 버튼 아래에 미니맵이 표시된다. 미니맵은 DPI 적용 전 280×280이며, 이 맵의 퀘스트 안내는 미니맵 아래에 표시된다. 내 캐릭터를 중심으로 수평 반경 12m 안의 지형만 표시한다. 중앙의 파란 화살표는 캐릭터 방향을 따라 회전하고, 이동하면 주변 지형이 갱신된다. 녹색 이동 문 아이콘은 반경 안에 들어오면 나타난다. 마을과 필드를 오갈 때 도착한 지역의 지형과 문을 사용한다.

`T_TownMinimap`은 월드 원점을 중심으로 두 축의 ±1,800cm 안에 있는 광장과 건물을 표시한다. `T_FieldMinimap`은 월드 (55,400, 0)cm를 중심으로 두 축의 ±7,800cm를 담는다. 귀환 문에서 교역소와 숲길을 거쳐 폐성당으로 가는 길을 확인할 수 있다. +X는 위, +Y는 오른쪽이다. 두 지역은 같은 퍼시스턴트 월드에 있으므로 로컬 Pawn이 도착한 위치로 사용할 지도를 고른다. 문은 퍼시스턴트 레벨에 배치된 `RPGRegionGate`의 Region Level 설정과 실제 좌표로 표시한다.

`WBP_PlayerHUD`의 로컬 빙의 수명에 맞춰 네이티브 위젯을 부착한다. `/Game/Minimap`의 프레임·화살표·포털 아이콘은 GladiatorCore에서 가져온 텍스처이며, `PAL_TownMinimap`이 런타임 로드용 패키지의 쿠킹을 지정한다.

필드에서 Tab을 누르면 반투명 전체 지도가 열리고, 다시 누르거나 마을로 돌아오면 닫힌다. 밝은 선은 귀환 문 쪽에서 교역소와 숲길을 거쳐 폐성당으로 이어지는 주요 통행로다. 저작된 필드 지도에서 이 통행로를 추출해 `T_FieldOverview`에 구워 둔다. 맵을 수정할 때 지도 원본과 함께 갱신한다. 이 선은 저작된 안내 경로이며 이동 가능 면 전체나 실시간 경로 탐색 결과를 나타내지는 않는다.

전체 지도 텍스처는 HUD 생성 시 비동기로 로드한다. 지도가 열려 있을 때 화면에 텍스처와 캐릭터·포털 아이콘을 그린다. 닫혀 있는 전체 지도는 레이아웃에서 접혀 그리기와 틱을 건너뛴다.
