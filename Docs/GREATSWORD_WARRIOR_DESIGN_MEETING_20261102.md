# 대검 전사 구체 기획 회의와 설계 초안

회의일: 2026-11-02

후속 아이덴티티 설계는 [사용 시 게이지를 소비하는 폭주 회의](GREATSWORD_IDENTITY_DESIGN_MEETING_20261102.md)를 따른다. 사용자 최종 방향은 등록된 분노 스킬의 진입 쿨타임 초기화·폭주 중 사용마다 강화와 게이지 소비·자연 감소 없음이며, 아래의 기존 1회 강화와 지속형 폭주 검토는 당시 구현/논의 기록으로 구분한다.

**대검 전사는 버서커 계열 콘셉트로 설계한다.** 사용자 후속 선택에 따라 거친 양손 대검 공격과 투지를 쌓아 해방하는 전투 경험을 중심에 둔다. 빈틈의 길이와 적의 움직임을 읽고 큰 공격을 완수하는 판단도 유지한다. 차지는 멈춘 적에게 집중 피해를 넣고, 회전은 움직이는 적을 따라가거나 다수 적에게 공격을 유지하는 선택으로 구분한다.

사용자 요청으로 시니어 전투·직업 기획자 역할의 에이전트 5명이 자료 조사와 교차 검토를 진행했다. 버서커 계열 콘셉트는 아래 사용자 선택으로 반영하며, 그 밖의 회의 채택안은 제작 제안과 구현 사실을 구분한다. 기존 규칙은 [직업 설계 방향](PLAYABLE_CLASS_DESIGN_DIRECTION.md), [첫 성장 구간](PLAYER_PROGRESSION_FIRST_SLICE_V01.md), 실제 코드와 대조했다. 이번 변경은 이 회의 문서와 로드맵의 본인 조율 행뿐이다.

## 사용자 선택과 후속 설계 방향

2026-11-02 사용자 의견: “버서커가 주로 대검을 쓰니까 비슷한 컨셉으로 밀고나가도 좋다고봐”. 대검 전사의 콘셉트를 버서커 계열로 추진하는 방향을 채택한다. 이후 스킬·외형·연출·고유 능력의 구체화도 이 방향을 기준으로 한다.

- **전투 인상:** 넓고 힘 있는 베기, 돌진·강타·회전으로 밀어붙이는 공격성을 강조한다. 큰 공격의 무게와 위험을 읽는 판단을 함께 유지한다.
- **고유 능력 검토:** 공격으로 투지를 쌓고 해방할 때 공격의 위력이 두드러지는 경험을 목표로 한다. 현행 다음 주력기 1회 강화와 일정 시간 공격을 몰아치는 지속형 폭주를 비교할 수 있다. 지속형 폭주는 후속 설계 후보이며 이번 콘셉트 선택만으로 확정하지 않는다.
- **확정 범위:** 특정 게임의 버서커 규칙, 체력 소모·저체력 보너스·흡혈·상시 면역, 폭주 지속시간·공격 속도·스킬 교체는 아직 선택하지 않았다. 직업 이름도 가칭 대검 전사를 유지한다.

아래 회의의 중심 4개와 기존 투지 규칙은 현재 제작 기반이다. 사용자 방향은 고유 능력의 최종 형태를 다시 검토할 근거이며, 현재의 1회 강화를 최종 버서커 메커니즘으로 고정하는 뜻은 아니다. 이번 후속은 기획 기록이며 소스·에셋의 동작은 변경하지 않았다.

| 차지 취소 손실 | 투지·쿨타임·재접근 부담 때문에 주력기 사용을 기피할 수 있음 | 기존 비환급 유지. 부분 해제·조준 수정·회피 포기의 결과를 명확히 안내하고 연습 예고를 확보 |
| 빠른 스킬의 투지 | 저위험·저쿨 기술도 20이면 필수 수급기가 될 수 있음 | 신규 기술에 대한 최종 지급량은 미합의. 기존 4개 지급 규칙은 유지하며 비교 실험 후 결정 |
| 훈련에서 투지 사용 | 투지는 훈련 완료 후 해금되어 선행 요구가 불가능 | 기존 네 목표 유지. 투지 사용은 해금 이후의 선택 연습으로 배치 |

## 2. 현재 기준과 새 제안의 경계

|---|---|---|
| 직업 구성 | 최종 액티브 후보 12~16개, 편성 최대 8개. 기본 공격·회피·고유 능력 별도 | 유지. 첫 구간은 중심 4개이며 8칸을 자동으로 채우지 않음 |
| 자원 | 첫 중심 4개 마나 비용 0. 투지 최대 100 | 신규 스태미나·분노·결의 자원을 추가하지 않음. Resolve는 코드 이름 |
| 투지 획득 | 승인된 스킬 적중은 시전당 20, 기본 연계 전체 적중·완주 시 10 | 다단·다수 적중으로 중복 지급하지 않는 기존 동작 유지 |
| 투지 해방 | 100 소비, 10초 안의 다음 적격 차지 또는 회전 1회를 피해 25% 강화 | 기존 선택 유지. 차지 실행 방식의 완충 공격/해당 회전 시전에 적용하며 단순 태그만 같은 즉발 변형까지 자동 확대하지 않음 |
| 실패와 비용 | 승인 전 조준 취소·준비 실패에는 새 쿨타임 없음. Commit 성공 뒤 취소·빗나감은 쿨타임 비환급. 해방한 투지도 실패 시 비환급 | UI로 승인 전·후를 구분. 10초 안에 승인된 회전은 남은 타격이 기회 만료 뒤여도 해당 시전의 고정 강화로 취급 |
| 차지 해제 | 기본 차지는 부분 해제 허용. 일부 완충/빠른 충전 선택은 해제 하한을 최대 단계로 설정 | 모든 차지를 완충 전용이라고 설명하지 않음 |

| 무력화·파괴 | 차지·도약 기본 기여 각 20, 해당 선택 25. 회전 종료 무력화 20/선택 25·파괴 0의 콘텐츠 기록 | 피해 강화와 기여를 분리. 훈련 수신 100을 보스 그로기 기준으로 사용하지 않음 |

실제 투지 확인 근거는 [Resolve Ability](../Source/Project_RPG/Private/Ability/Skill/RPGGreatSwordResolveAbility.cpp), [스킬 적중과 중복 방지](../Source/Project_RPG/Private/Skill/RPGGameplayAbility_SkillContainer.cpp), [기본 연계 완주](../Source/Project_RPG/Private/Ability/RPGComboSkillAbility.cpp)다. 기존 문서의 수치 목표와 에셋 저장·실행 검증 범위는 서로 다르다. 아래 피해 계수나 시간 목표를 현재 모든 운영 에셋의 실측값으로 읽지 않는다.

## 3. 전투 정체성과 상황별 선택

중갑과 양손 대검의 무게를 준비 자세, 칼날 이동, 타격 후 자세 회복으로 표현한다. 대검의 강점은 큰 공격을 맞힐 기회를 판단하는 데 있고, 약점은 접근·충전·착지·후딜 때문에 안전한 공격 시간을 놓칠 수 있다는 점이다. 강한 공격을 무조건 누르는 것보다 위험한 공격을 포기하는 판단도 보상받아야 한다.

| 전투 상황 | 권장 선택 | 남기는 부담 |
|---|---|---|
| 적이 멀리 있고 공격 예고가 없음 | 걸어서 위치 조정 또는 돌진 접근 | 돌진을 공격에 쓰면 같은 이동 수단을 즉시 다시 쓸 수 없음 |
| 짧고 불확실한 빈틈 | 기본 공격 일부, 추후 빠른 횡베기 | 연계 완주 투지나 큰 피해를 포기 |
| 멈춘 적의 긴 빈틈 | 투지 해방 후 완충 차지 | 충전·방출 중 적이 움직이면 실패 가능 |
| 이동하는 단일 적 또는 모여 있는 적 | 회전, 필요하면 투지 강화 | 공격을 유지할수록 노출. 조기 종료하면 남은 타격 포기 |
| 큰 공격 예고가 겹침 | 공격 준비 취소 후 기본 회피 | 이미 승인된 비용은 남지만 생존을 확보 |
| 잠깐 접근할 수 없는 구간 | 추후 검풍으로 견제 | 원거리 지속 공격수 수준의 피해 효율은 제공하지 않음 |

예시: 돌진으로 측면 접근 → 기본 1타 → 적의 예고를 보고 연계 중단 → 회피 → 적이 멈추면 투지 해방·완충 차지, 이동을 이어가면 회전으로 대응 → 후딜을 고려해 이탈한다. 투지 해금 전에는 해방 단계 없이 같은 기회 판단을 익힌다. 이 순서는 강제 콤보나 최적 고정 순환이 아니다.

파티에서는 기존 무력화·파괴 참여와 기회 중 집중 피해가 강점이다. 대검이 없어도 공통 기믹에 참여할 수 있어야 한다. 직업의 독립 전투 성립과 솔로 보스 제공은 별개이며, 첫 구간의 파티 기준은 기존 2인이다.

## 4. 기본 조작과 취소 규칙 제안

키는 현재 입력 설정과 슬롯에서 읽는다. 고정 Q/E 등의 새 배치를 요구하지 않고 기본 공격, 회피, 스킬 슬롯, 고유 능력의 기존 입력 구분을 사용한다.

| 구간 | 조작 제안 | 비용·판정 |
|---|---|---|
| 조준·승인 전 | 조준 변경과 취소 가능 | 실패한 준비에 새 쿨타임·피해를 만들지 않음 |
| 기본 공격 | 3단 후보: 1·2타는 짧은 기회, 마지막은 큰 보상. 홀드와 다음 입력 예약 유지 | 도중 회피하면 완주 보상 없음. 정확한 타수·전환은 모션 확인 후 결정 |
| 차지 준비·유지 | 충전 중 방향 조정, 기본 차지는 부분 해제, 회피로 포기 가능하게 설계 | 승인된 쿨타임·투지 비환급. 자유 이동 충전까지 동시에 추가하지 않음 |
| 공격 방출·타격 | 방출 시 방향 확정. 적을 따라 급회전하지 않음 | 실제 타격 구간에는 즉시 회피 취소를 허용하지 않는 안 |
| 타격 후 회복 | 후딜 후반부터 회피 가능하게 설계 | 무게 회복 구간을 전부 지우지 않음. 정확한 시점은 애니메이션 기준으로 작성 |
| 회전 유지·종료 | 유지 입력·해제 흐름을 사용. 해제 종료와 강제 중단을 구별 | 이미 승인된 적중은 유지하고 남은 타격은 포기. 정상 종료타를 얻는 조건과 피격/회피 중단의 처리 차이를 후속 구현 계약에서 명시 |
| 고유 능력 | 투지가 찼을 때 해방을 선택하고 다음 적격 주력기에 사용 | 준비·남은 기회 시간·사용됨·만료됨을 구분해서 표시 |

준비·타격·후딜의 정확한 경계, 회전 중 회피 처리, 입력 예약 길이는 신규 기획 대상이다. 현재 코드에 정밀 캔슬 창이 완성됐다고 가정하지 않는다. 검 궤적과 충돌 판정, 서버 승인 이동과 벽 충돌을 함께 확인한 뒤 구간을 확정한다. 상시 경직 면역을 기본 제공하지 않으며, 향후 제한된 면역을 검토하더라도 강한 제어·잡기·기믹 회피를 대체하지 않는다.

## 5. 중심 4개와 확장 4개

첫 네 기술의 피해와 시간은 기존 첫 구간 비교 가설이다. 쿨타임 8/10/12/10초와 마나 0은 후속 콘텐츠 기록에도 반영되어 있지만 피해·동작 목표 전체의 실측 완료를 뜻하지 않는다.

| 스킬 | 선택 이유와 조작 | 비교 기준 | 포기하는 것·제작 상태 |
|---|---|---|---|
| 돌진 베기 | 전방 접근과 공격을 결합 | 공격력×1.2, 쿨 8초 | 무적 회피 대체로 만들지 않음. 기존 중심기 AssultBlade 재사용 |
| 도약 강타 | 가까운 지점의 다수 적·파괴 기회 공략 | ×1.8, 쿨 10초 | 착지 위치 위험. 기존 JumpSmash 재사용 |
| 차지 슬래시 | 정지한 긴 빈틈의 집중 피해, 홀드 후 해제 | 완충 ×2.8, 쿨 12초, 완충 1.2초 목표 | 준비·방출 부담. 기존 ChargeSlash와 선택 변형 재사용 |
| 회전 베기 | 유지 입력으로 이동 단일·다수전 공격 지속 | 전체 ×2.4, 쿨 10초, 지속 2초 목표 | 노출·중단 손실. 이동형/제자리형 선택과 기존 WhirlWind 재사용 |
| 빠른 횡베기 | 짧은 빈틈에 쓰는 단발 공격 | 신규. 기본 1타보다 한 슬롯을 쓸 이유가 있어야 함 | 저쿨 투지 발전기 필수화 확인 전 채택 보류 |
| 반격 베기 | 짧은 정면 대응 성공을 공격으로 전환 | 신규. 대응 창과 실패 회복을 갖는 선택기 | 일반 정면 공격에 한정하는 안. 잡기·지면 기믹 대응 제외. 지속 가드/파티 보호 없음 |
| 검풍 | 잠깐의 접근 불가 상황에 쓰는 제한적 중거리 공격 | 신규. 근접 주력보다 낮은 지속 효율 목표 | 원거리에서 기다리는 상시 정답이 되면 재조정. 투사체/판정/모션 제작 필요 |
| 후퇴 베기 | 짧은 공격 뒤 거리를 벌리는 재배치 | 신규 조건부 8번째 후보. 무적 없음 | 기본 회피와 돌진을 모두 대체하면 제외. 공격→후퇴 모션 적합성 확인 필요 |

확장 4개의 피해·쿨타임·투지 지급량은 이번 회의에서 확정하지 않았다. 단순히 기존 스킬당 20을 낮은 쿨타임 기술에 붙이지 않고, 노출시간당 피해·투지·강화 주기까지 비교한다. 반격의 피해 경감량·대응 시간·성공 판정도 후속 설계 대상이다.

8개가 모두 검증되면 차지 중심은 큰 정지 기회, 회전 중심은 추적·유지, 대응 중심은 짧은 공격과 재배치를 잘 활용해야 한다. 슬롯 수만 같고 항상 동일한 8개가 필수라면 최종 12~16개 중 선택하는 목표를 달성한 것이 아니다.

후보를 12개 이상으로 늘릴 때에는 각 후보에 대해 **언제 넣는지, 무엇을 빼는지, 무엇을 포기하는지**가 있어야 한다. 그 기준 없이 새 스킬명을 채우지 않는다. 같은 내려찍기의 피해·범위 변화는 먼저 트라이포드로 검토한다.

화면에는 충전 단계, 투지 수치, 강화 준비와 남은 10초, 소비·만료를 구분한다. 거리 밖·부분 충전·피격 중단을 같은 실패 문구로 묶지 않는다. 기본 회피와 무적 없는 후퇴 베기도 구분한다. 실제 재지정 키를 표시하고 색 외에 문구·형태·소리를 병행한다.

회피 취소는 위험을 읽은 판단으로 설명한다. 초보 연습에서는 충분한 공격 예고를 제공하고, 공격을 포기했는데도 연속 피격으로 손실이 누적되는 상황부터 요구하지 않는다. 핵심 생존과 기회 판단을 특정 무기 획득 이후에만 제공하지 않는다.

## 8. 밸런스 검토와 다음 제작 순서

이번 회의는 아래 플레이 비교를 실행하지 않았다. 표는 후속 기획 검증의 조건이며 새 테스트 코드나 빌드 예약이 아니다.

| 비교 | 조건 | 판단 기준 |
|---|---|---|
| 차지·회전 기본 성능 | 동일 장비·동일 투자, 정지 표적 60초 | 기존 목표인 전체 피해 차이 10% 이내를 출발점으로 사용 |
| 공격 기회 선택 | 새 실험 조건: 안전 시간 0.8/2.5/4초, 정지/이동, 적 1/5체 | 짧은 공격·차지·회전 각각 유리한 조건이 있어야 함. 이 시간은 에셋 길이가 아님 |
| 투지 운용 | 기존 4개와 빠른 기술 추가 구성을 비교 | 노출시간당 피해/투지, 강화 횟수, 생존을 비교. 횡베기 하나가 모든 구성을 지배하면 재조정 |
| 중단 손실 | 부분 차지, 회전 중단, 회피 후 재접근 | 사망 회피의 이점이 남아야 함. 회전의 피해·기여·장비 보상이 마지막 타격에 과도하게 몰리지 않는지 확인 |
| 파티 기여 | 기본 2인과 3/4인, 향후 대검 비중이 다른 구성 | 무력화 횟수·안전 시간·전체 피해의 연쇄 증가를 측정. 훈련의 100 기준을 보스에 복사하지 않음 |
| 조작·표현 | 취소 전후, 벽 앞, 이동 적, 소유자와 관찰자 | 검 궤적·판정·위치 일치, 입력에 대한 예측 가능한 응답, 전투 예고 가독성 |

기존 피해 가설에서 투지 강화의 추가 피해는 완충 차지 `공격력×0.7`, 회전 전체 `공격력×0.6`이다. 이는 같은 투자·전타 적중의 산술이며 실제 강화 효율은 적중률·전환 시간·남은 빈틈에 따라 달라진다. 이 수치만으로 차지 강화가 항상 정답이라고 결론내리지 않는다.

후속 제작은 다음 순서가 적절하다.

1. 기존 캐릭터·몽타주로 중심 4개를 시각 확인하고 실제 공격·회복·이동 구간을 기록한다.
2. 기본 공격·차지·회전의 취소와 조준 규칙을 현 구현과 대조해 필요한 차이만 구현한다.
3. 기존 훈련과 별개로 짧은/긴 빈틈과 이동 표적에서 두 주력기의 선택을 비교한다.
4. 횡베기를 기본 1타와 비교한 뒤 검풍·반격·후퇴 베기를 개별 검토한다. 유효한 역할이 있는 기술만 편성 후보에 추가한다.
5. 조건부 8개와 투지 경제가 성립한 뒤 12~16개 후보로 확장한다.

현재 남겨 둔 설계 판단은 정확한 모션·캔슬 경계, 신규 4개 수치와 투지 지급, 반격 판정, 후퇴 공격 모션 적합성, 최종 캐릭터 외형이다. 이번 회의에서는 제안의 장단점과 확인 조건까지 정리했으며 이를 이미 승인·구현된 규칙으로 바꾸지 않았다.

## 9. 조사 범위와 보존 기록

원본 에셋과 코드의 읽기 전용 조사, 5인 의견 교환, 회의 문서의 경로·규칙 대조를 수행했다. 에셋 직접 재생, 리타깃 확인, 플레이 밸런스 검사, 게임 빌드는 수행하지 않았다. 공유 소스·에셋·기존 계약 문서는 수정하지 않았다.

주요 근거는 상위 직업·첫 구간 문서, [스킬 아키텍처와 운영 에셋 기록](SKILL_AND_TRIPOD_MODULAR_ARCHITECTURE.md), 위에 연결한 투지·기본 연계·스킬 컨테이너·훈련 소스와 실제 에셋 경로다. 동시 진행 중인 프로젝트의 시점 조사이므로 다른 담당의 후속 변경까지 고정 검증한 것으로 취급하지 않는다.

최종 문서의 상대 링크 10개와 명시한 전체 에셋 경로 13개의 존재, 파일 집계 3,164/88/96개를 대조했다. 직업 디렉터가 기존 규칙·조작·스킬·성장 절을 재검토하여 기존 계약과 충돌하는 문장이 없음을 확인했다. 이는 문서 검토이며 게임 실행 검증이 아니다.

임시 산출물 생성 0 bytes, 삭제 0 bytes, 보존 예외 없음. 이 문서는 사용자에게 전달하는 최종 회의 산출물로 유지한다.
